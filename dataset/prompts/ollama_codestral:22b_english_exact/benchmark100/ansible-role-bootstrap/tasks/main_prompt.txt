 Below you will receive task descriptions from which you should generate an Ansible Playbook.
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

Task 1: Import assert.yml
Description Task 1: This task imports the assert.yml file from the same directory to run assertions that can help verify the state of the system.

Task 2: Wait for port to be available
Description Task 2: This task waits for a specified port (defaulting to 22) to become available before continuing. This is useful when connecting to a new host and waiting for the SSH service to start. The timeout is defined by the variable 'bootstrap_timeout'.

Task 3: Prepare system
Description Task 3: This task block is responsible for testing the connection and checking if sudo is installed on the system. If the connection or sudo test fails, it resorts to the 'rescue' block to gather facts and install necessary bootstrap packages.

Task 4: Gather ansible facts
Description Task 4: This task gathers facts about the system, which can be used in later tasks.

Task 5: Install bootstrap packages (package)
Description Task 5: This task installs a list of packages defined in the 'bootstrap_facts_packages' variable. The package state is set to 'present' to ensure the packages are installed, and 'update_cache' is set to true to update the package cache before installing. The 'become' flag is set to the value of the 'bootstrap_become' variable to determine whether privilege escalation is required.
