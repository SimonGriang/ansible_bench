 Below you will receive task descriptions from which you should generate an Ansible Playbook.
   The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).
   Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

   Task 1: Create a local SSH key directory for a specific user if manage_ssh_key is defined and set to true.
   Description Task 1: This task creates a directory to store SSH keys for the user on the localhost. The directory path is specified by the 'users_ssh_key_directory' variable. The directory is created with a mode of 0750.

   Task 2: Manage a user account based on the provided details.
   Description Task 2: This task uses the 'ansible.builtin.user' module to create or modify a user account. It sets properties such as the username, state, comment, create_home, password, uid, group, groups, home, shell, update_password, expires, and system based on the 'user' variable.

   Task 3: Set sudo options for a specific user if sudo_options are defined.
   Description Task 3: This task uses the 'ansible.builtin.template' module to create a sudoer file for the user if sudo_options are defined. The file is created from a template named 'sudo.j2' and placed in the '/etc/sudoers.d/' directory. The file mode is set to 0640 and the file is validated using '/usr/sbin/visudo --check --file %s'.

   Task 4: Remove sudo options for a specific user if sudo_options are not defined.
   Description Task 4: This task uses the 'ansible.builtin.file' module to remove the sudoer file for the user if sudo_options are not defined. The file is located in the '/etc/sudoers.d/' directory.

   Task 5: Generate a private SSH key for a specific user if manage_ssh_key is defined and set to true.
   Description Task 5: This task uses the 'ansible.builtin.command' module to generate a private SSH key for the user. The command used is specified by the 'users_ssh_keygen_command' variable. The key is stored in the directory specified by the 'users_ssh_key_directory' variable. The task runs on the localhost and does not use privilege escalation.

   Task 6: Generate a public SSH key for a specific user if manage_ssh_key is defined and set to true.
   Description Task 6: This task uses the 'ansible.builtin.shell' module to generate a public SSH key for the user. The command used is specified by the 'users_ssh_keygen_pubkey_command' variable. The key is stored in the directory specified by the 'users_ssh_key_directory' variable. The task runs on the localhost and does not use privilege escalation.

   Task 7: Convert the private SSH key to a ppk format for a specific user if manage_ssh_key is defined and set to true.
   Description Task 7: This task uses the 'ansible.builtin.shell' module to convert the private SSH key for the user to a ppk format. The command used is 'ssh-keygen -e -f "{{ users_ssh_key_directory }}/{{ user.name }}" -C "Generated by Ansible role robertdebock.users"'. The converted key is stored in the directory specified by the 'users_ssh_key_directory' variable. The task runs on the localhost and does not use privilege escalation.

   Task 8: Get or set the home directory for a specific user.
   Description Task 8: This task uses the 'ansible.builtin.getent' module to get the home directory for the user. If the user is not found, the task sets the home directory to '/home'.

   Task 9: Create a .ssh directory for a specific user if manage_ssh_key is defined and set to true or if private_keys are defined.
   Description Task 9: This task uses the 'ansible.builtin.file' module to create a .ssh directory for the user in their home directory. The directory is created with a mode of 0700. The task uses privilege escalation to run as the user.

   Task 10: Deploy authorized keys for a specific user if authorized_keys are defined.
   Description Task 10: This task uses the 'ansible.posix.authorized_key' module to deploy authorized keys for the user. The keys are specified by the 'authorized_keys' variable.

   Task 11: Remove unauthorized keys for a specific user if unauthorized_keys are defined.
   Description Task 11: This task uses the 'ansible.posix.authorized_key' module to remove unauthorized keys for the user. The keys are specified by the 'unauthorized_keys' variable.

   Task 12: Copy a generated private SSH key for a specific user to their .ssh directory if copy_private_key is defined and set to true.
   Description Task 12: This task uses the 'ansible.builtin.copy' module to copy a generated private SSH key for the user to their .ssh directory. The key is copied from the directory specified by the 'users_ssh_key_directory' variable. The key is owned by the user and has a mode of 400.

   Task 13: Check the password valid time for a specific user.
   Description Task 13: This task uses the 'ansible.builtin.command' module to check the password valid time for the user. The command used is 'awk 'BEGIN { FS = ":" } $1 == "{{ user.name }}" { print $5 }' /etc/shadow'.

   Task 14: Set the password valid time for a specific user if password_validity_days is defined and the current password valid time does not match the desired password valid time.
   Description Task 14: This task uses the 'ansible.builtin.command' module to set the password valid time for the user. The command used is 'chage -M "{{ user.password_validity_days }}" "{{ user.name }}"'. The task only runs if the current password valid time does not match the desired password valid time.

   Task 15: Place a private key file for a specific user in their .ssh directory if private_keys are defined.
   Description Task 15: This task uses the 'ansible.builtin.copy' module to place a private key file for the user in their .ssh directory. The key file content is specified by the 'content' property of the 'private_keys' variable. The key file is owned by the user and has a mode of 400.
