Task 2: Configure Sudo options for the group
Description Task 2: This task sets the sudo options for a specified group if sudo options are defined. It uses a template to create the sudoers file for the group with the specified mode and validates it using visudo.
Task 2 Ansible Code:
- name: group | Set sudo options for group {{ group.name }}
  ansible.builtin.template:
    src: sudo_group.j2
    dest: '/etc/sudoers.d/{{ group.name | replace(".", "dot") }}'
    mode: "0640"
    validate: /usr/sbin/visudo -cf %s
  when:
    - group.sudo_options is defined
  loop_control:
    label: "{{ group.name }}"
