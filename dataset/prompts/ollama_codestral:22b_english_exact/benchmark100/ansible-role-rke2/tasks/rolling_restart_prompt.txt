Task 1: Cordon and Drain the node
Description Task 1: This task is responsible for marking the node as unschedulable and evacuating all its running pods. This is done using kubectl commands. It's performed when the variable 'rke2_drain_node_during_upgrade' is true. The kubectl commands are executed on the 'active_server' if it's defined, otherwise they are executed on the first server in the 'rke2_servers_group_name' group.

Task 2: Restart RKE2 service
Description Task 2: This task restarts the RKE2 service on the target node. This is necessary after performing an upgrade or a similar operation that requires a service restart. The service name is defined by the variable 'rke2_service_name'.

Description Task 3: This task waits until all nodes in the cluster are marked as 'Ready' in the Kubernetes API. It uses a kubectl command to count the number of ready nodes and retries until it matches the total number of nodes in the cluster. The kubectl command is executed on the 'active_server' if it's defined, otherwise it's executed on the first server in the 'rke2_servers_group_name' group.

Description Task 4: This task marks the node as schedulable again after it has been drained and upgraded. This is done using a kubectl command. It's performed when the variable 'rke2_drain_node_during_upgrade' is true. The kubectl command is executed on the 'active_server' if it's defined, otherwise it's executed on the first server in the 'rke2_servers_group_name' group.
