 Below you will receive task descriptions from which you should generate an Ansible Playbook.
   The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).
   Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

   Task 1: Download RKE2 kubeconfig to localhost
   Description Task 1: This task is responsible for fetching the RKE2 kubeconfig file from the master server to the localhost. This action is performed only when the 'rke2_download_kubeconf' variable is set to true and if the current host is the first server in the 'rke2_servers_group_name' group. The downloaded file is saved to a specific path and file name as defined by the 'rke2_download_kubeconf_path' and 'rke2_download_kubeconf_file_name' variables.

   Task 2: Replace loopback IP by master server IP
   Description Task 2: This task is responsible for replacing the loopback IP (127.0.0.1 or [::1]) in the downloaded RKE2 kubeconfig file with the master server IP. This action is performed on the localhost and only when the current host is the first server in the 'rke2_servers_group_name' group and the 'rke2_download_kubeconf' variable is set to true. The master server IP used for replacement is defined by the 'rke2_api_ip' variable, which defaults to the 'ansible_host' variable of the first server in the 'rke2_servers_group_name' group. The modified file is saved to the same path and file name as defined by the 'rke2_download_kubeconf_path' and 'rke2_download_kubeconf_file_name' variables. The file mode is also set to '0600'.
