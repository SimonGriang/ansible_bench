   Task 2: Configure apk

   Task 4: Update all software (dnf)

   Task 5: Update all software (pacman)
   Description Task 5: When the package manager is pacman, update the cache and then upgrade all software. Notify the Reboot handler after the upgrade.

   Task 6: Configure yum
   Description Task 6: When the package manager is yum, update all software excluding those specified in the update_excluded_packages variable and notify the Reboot handler after the upgrade. If the distribution major version is not 6, install yum-utils.

   Description Task 7: When the package manager is zypper, update all software. Notify the Reboot handler after the upgrade.
