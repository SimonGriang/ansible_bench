   Task 1: Install epel

   Task 4: Install epel-next-release
   Description Task 4: Conditionally installs the EPEL next repository. The repository URL is defined by the variable "epel_next_url". This task is only executed when the variable "epel_next" is true. After installation, it triggers the handler "Update package cache".
