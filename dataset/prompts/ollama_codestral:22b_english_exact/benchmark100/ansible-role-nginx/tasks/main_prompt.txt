 Below you will receive task descriptions from which you should generate an Ansible Playbook.
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

Task 1: Import assert.yml
Description Task 1: Import a local assertion task file into the playbook. This file is run once and only on the localhost to ensure that necessary variables are defined.

Task 2: Install nginx
Description Task 2: Use the package module to ensure that the nginx package is installed on the target system.

Task 3: Place nginx.conf
Description Task 3: Use the template module to place the nginx configuration file in the appropriate location. Validate the configuration file using the 'nginx -t -c' command. If the configuration is valid, notify the handler to restart the nginx service.

Task 4: Ensure /etc/nginx/conf.d exists
Description Task 4: Ensure that the directory /etc/nginx/conf.d exists and has the correct permissions.

Task 5: Place default.conf
Description Task 5: Use the template module to place the default configuration file in the appropriate location. If the configuration is valid, notify the handler to restart the nginx service.

Task 6: Start and enable nginx
Description Task 6: Use the service module to ensure that the nginx service is started and enabled at boot.
