Task 1: Create directories
Description Task 1: Create the directories specified in the variable httpd_directories with a permission mode of 0755.

Task 2: Configure directories
Description Task 2: Utilize a template (directory.conf.j2) to configure the directories listed in the variable httpd_directories. The configuration files will be created with the name of each directory in the httpd_directories variable, under the httpd_config_directory directory. The files will have a permission mode of 0644. After creating these files, notify the handlers to test the httpd configuration validity and to restart the httpd service.
