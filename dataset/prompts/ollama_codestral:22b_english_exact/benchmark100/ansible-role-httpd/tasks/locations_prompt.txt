   Task 1: Enable modules in Apache

   Task 2: Configure locations in Apache
   Description Task 2: This task uses the 'ansible.builtin.template' module to configure locations in Apache. It uses a J2 template called 'location.conf.j2' and places the configured files in '{{ httpd_config_directory }}'. Each configuration is looped from the 'httpd_locations' variable. After configuration, it triggers two handlers: 'Test httpd configuration validity' and 'Restart httpd'. The looped items are labelled with '{{ item.name }}'.
