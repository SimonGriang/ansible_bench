 Task 1: password | Get efi path
   Description Task 1: This task checks if the EFI (Extensible Firmware Interface) directory exists to determine the system's boot method.

   Task 2: password | Remove unwanted grub.cfg on EFI systems
   Description Task 2: If the EFI directory exists, this task removes the unwanted grub.cfg file to prepare for the new configuration.

   Task 3: password | Install user template
   Description Task 3: This task installs a user template (01_users.j2) to the /etc/grub.d/01_users directory with specific permissions.

   Task 4: password | EFI | add password
   Description Task 4: If the EFI directory exists, this task adds a password to the /etc/grub2-efi.cfg file using the grub_user and grub_password variables.

   Task 5: password | MBR | add password
   Description Task 5: If the EFI directory exists, this task adds a password to the /etc/grub2.cfg file using the grub_user and grub_password variables.

   Task 6: password | Add --unrestricted
   Description Task 6: If the grub_password_unrestricted variable is true, this task adds the --unrestricted flag to the files listed in the grub_password_unrestricted_files variable.
