 Task 1: Create SSL key
   Description Task 1: Create a private key for SSL certificate. The key will be saved in the specified directory with the specified name. The owner and group of the file will be set according to variables. The permission mode for the file will be 600.

   Task 2: Create SSL CSR
   Description Task 2: Create a Certificate Signing Request (CSR) using the previously created private key. The CSR will be saved in the specified directory with the specified name. The common name will be set using the variable. The owner and group of the file will be set according to variables. The permission mode for the file will be 640.

   Task 3: Create SSL certificates
   Description Task 3: Create a self-signed SSL certificate using the private key and CSR. The certificate will be saved in the specified directory with the specified name. The owner and group of the file will be set according to variables. The permission mode for the file will be 640.

   Task 4: Create PKCS#12 file
   Description Task 4: Create a PKCS#12 file containing the private key and the certificate. The file will be saved in the specified directory with the specified name. The owner and group of the file will be set according to variables. The permission mode for the file will be 600.

   Task 5: Read private key
   Description Task 5: Read the content of the private key file and store it in a variable for further use.

   Task 6: Read certificate
   Description Task 6: Read the content of the certificate file and store it in a variable for further use.

   Task 7: Create combined private_key and certificate file
   Description Task 7: Create a file containing both the private key and the certificate. The file will be saved in the specified directory with the specified name. The owner and group of the file will be set according to variables. The permission mode for the file will be 600.
