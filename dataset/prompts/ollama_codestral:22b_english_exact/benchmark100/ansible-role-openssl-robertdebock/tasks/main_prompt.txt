 Below you will receive task descriptions from which you should generate an Ansible Playbook.
   The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).
   Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

   Task 1: Import assert.yml
   Description Task 1: This task is to import the assert.yml file, which ensures that the necessary variables are defined. This is typically executed once and on the localhost.

   Task 2: Install requirements
   Description Task 2: This task is to install the requirements listed in the openssl_requirements variable. These requirements are essential for the OpenSSL certificate creation process.

   Task 3: Install pip packages
   Description Task 3: This task is to install the Python packages listed in the openssl_pip_packages variable. These packages are required for certain OpenSSL operations.

   Task 4: Create key directory
   Description Task 4: This task is to create a directory for storing private keys. The directory should be created with a mode of 700, and the ownership should be set to the user and group specified in the openssl_file_owner and openssl_file_group variables.

   Task 5: Create csr directory
   Description Task 5: This task is to create a directory for storing certificate signing requests (CSRs). The directory should be created with a mode of 755, and the ownership should be set to the user and group specified in the openssl_file_owner and openssl_file_group variables.

   Task 6: Create crt directory
   Description Task 6: This task is to create a directory for storing certificates. The directory should be created with a mode of 755, and the ownership should be set to the user and group specified in the openssl_file_owner and openssl_file_group variables.

   Task 7: Include create.yml
   Description Task 7: This task is to include the create.yml file, which contains the logic for creating OpenSSL certificates. This task is looped over the items in the openssl_items variable, and each iteration is labeled with the name of the current item.
