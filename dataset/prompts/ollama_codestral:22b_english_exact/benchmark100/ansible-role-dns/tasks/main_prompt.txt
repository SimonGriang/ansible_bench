 Below you will receive task descriptions from which you should generate an Ansible Playbook.
   The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).
   Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

Task 1: Import assert.yml
Description Task 1: Import the assert.yml file to ensure the role is used correctly.

Task 2: Install dns
Description Task 2: Install the necessary DNS packages on the system.

Task 3: Create directories
Description Task 3: Create directories for DNS data and configuration files with specific permissions, ownership, and group.

Task 4: Create group
Description Task 4: Create a group for the DNS service.

Task 5: Create user
Description Task 5: Create a user for the DNS service with system privileges.

Task 6: Generate rndc key
Description Task 6: Generate a key for rndc (DNS control) using rndc-confgen and save it to the configuration directory.

Task 7: Set permissions on rndc key file
Description Task 7: Set the permissions, ownership, and group of the rndc key file to ensure security.

Task 8: Get the hints/root file
Description Task 8: Download the hints/root file from the Internet and save it to the data directory. This step is conditional and only runs when caching DNS is enabled.

Task 9: Create zone file
Description Task 9: Create zone files based on a template for each DNS zone and save them to the data directory. This step is conditional and only runs for primary zones.

Task 10: Add zones to configuration
Description Task 10: Add zones to the DNS configuration file based on a template.

Task 11: Place systemd override
Description Task 11: Configure systemd to override the DNS service's default configuration. This step is conditional and only runs when systemd is the service manager.

Task 12: Start and enable dns
Description Task 12: Start the DNS service and enable it to start on boot.
