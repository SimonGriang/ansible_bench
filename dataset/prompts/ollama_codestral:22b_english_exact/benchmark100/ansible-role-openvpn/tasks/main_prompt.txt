 Below you will receive task descriptions from which you should generate an Ansible Playbook.
   The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).
   Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

   Task 1: Import assert.yml
   Description Task 1: This task asserts that the necessary variables are defined before proceeding with the playbook. It runs once on the localhost and delegates the task to the localhost.

   Task 2: Install openvpn packages
   Description Task 2: This task installs the packages required for OpenVPN as defined in the variable openvpn_packages.

   Task 3: Setup openvpn server or client
   Description Task 3: This task includes the specific tasks for setting up OpenVPN as a server or a client based on the value of the openvpn_role variable.

   Task 4: Start and enable openvpn
   Description Task 4: This task starts the OpenVPN service as defined in the openvpn_service variable and enables it to start at boot time.
