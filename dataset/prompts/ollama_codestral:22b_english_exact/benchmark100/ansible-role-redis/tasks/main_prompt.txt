 Below you will receive task descriptions from which you should generate an Ansible Playbook.
   The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).
   Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

   Task 1: Import assert.yml
   Description Task 1: This task imports the assert.yml file, which is responsible for verifying prerequisites. This is a one-time task that runs on the localhost.

   Task 2: Enable redis module stream (RHEL 8)
   Description Task 2: This task enables the redis module stream on Red Hat Enterprise Linux 8. It does this by using the dnf package manager to change the state of the redis package to enabled.

   Task 3: Install redis
   Description Task 3: This task installs the redis package. It uses the package module and the variable "redis_packages" to specify which package to install.

   Task 4: Configure redis
   Description Task 4: This task configures the redis service. It uses the template module to copy a configuration file from the src directory to the destination directory. The configuration file is specified using the variables "redis_configuration_directory", "redis_configuration_file", "redis_owner", "redis_group", and "redis_mode". If the configuration file changes, it notifies the "Restart redis" handler to restart the redis service.

   Task 5: Start and enable redis
   Description Task 5: This task starts the redis service and enables it to start on boot. It uses the service module and the variable "redis_service" to specify the service name. The service is set to a state of started and enabled.
