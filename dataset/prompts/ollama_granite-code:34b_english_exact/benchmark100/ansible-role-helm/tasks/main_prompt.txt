Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Check if Helm binary exists.
Description Task 1: This task checks if the Helm binary exists by using the stat module. The path to the Helm binary is defined by the helm_bin_path variable. The result of the check is stored in the helm_check variable.

Task 2: Check Helm version.
Description Task 2: This task checks the version of the Helm binary by using the command module. The version command is executed by using the helm_bin_path variable. The result of the check is stored in the helm_existing_version variable. The failed_when and changed_when options are set to false to prevent playbook failure and unnecessary changes.

Task 3: Download helm.
Description Task 3: This task downloads the Helm binary by using the unarchive module. The source file is downloaded from the helm_repo_path variable, and the destination directory is /tmp. The remote_src option is set to true to indicate that the file is on the remote system. The mode option is set to 0755 to ensure the correct permissions are set on the downloaded file. The result of the download is stored in the helm_download variable. The task only runs if the helm_check.stat.exists or helm_version not in helm_existing_version.stdout conditions are met.

Task 4: Copy helm binary into place.
Description Task 4: This task copies the Helm binary into the correct location by using the copy module. The source file is the Helm binary downloaded in the previous task, and the destination directory is defined by the helm_bin_path variable. The mode option is set to 0755 to ensure the correct permissions are set on the copied file. The remote_src option is set to true to indicate that the file is on the remote system. The become option is set to true to run the task with administrative privileges. The task only runs if the helm_download is changed condition is met.
