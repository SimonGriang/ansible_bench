Task 1: Import assert.yml
Description Task 1: This task imports the assert.yml file which is located in the same directory as the current task. This file contains assertions that will be used to validate the state of the system.

Task 2: Install vsftpd
Description Task 2: This task installs the vsftpd package using the package module.

Task 3: Configure vsftpd
Description Task 3: This task configures the vsftpd service by copying the contents of the vsftpd.conf.j2 template to the destination file specified by the vsftpd_configuration_file variable. The owner, group, and mode of the destination file are set to root, root, and the value of vsftpd_configuration_file_mode, respectively. This task also notifies the handler named Restart vsftpd.

Task 4: Start and enable vsftpd
Description Task 4: This task starts and enables the vsftpd service using the service module.
