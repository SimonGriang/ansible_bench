Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Create the RKE2 config dir
Description Task 1: Create the directory /etc/rancher/rke2 with the owner, group, and permissions set to root.

Task 2: Set server taints
Description Task 2: Set the variable combined_node_taints to the value of rke2_server_node_taints if the rke2_type is 'server'.

Task 3: Copy rke2 config
Description Task 3: Copy the file specified by rke2_config to /etc/rancher/rke2/config.yaml with the owner, group, and permissions set to root.

Task 4: Copy kubelet config
Description Task 4: Copy the file specified by rke2_config to /etc/rancher/rke2/config.yaml with the owner, group, and permissions set to root.

Task 5: Copy Containerd Registry Configuration file
Description Task 5: Copy the file specified by rke2_custom_registry_path to /etc/rancher/rke2/registries.yaml with the owner, group, and permissions set to root.

Task 6: Register if we need to do a etcd restore from file
Description Task 6: Set the variable do_etcd_restore to true if rke2_etcd_snapshot_file is not empty and rke2_server is not running.

Task 7: Register if we need to do a etcd restore from s3
Description Task 7: Set the variable do_etcd_restore_from_s3 to true if rke2_etcd_snapshot_file is not empty and rke2_etcd_snapshot_s3_options is defined with access_key, secret_key, bucket, and snapshot_name.

Task 8: Restore etcd from file
Description Task 8: Restore etcd from a file if do_etcd_restore is true.

Task 9: Restore etcd from s3
Description Task 9: Restore etcd from a s3 snapshot if do_etcd_restore_from_s3 is true.

Task 10: Start RKE2 service on the first server
Description Task 10: Start the RKE2 server service with the token set to rke2_token.

Task 11: Mask RKE2 agent service on the first server
Description Task 11: Mask the RKE2 agent service.

Task 12: Wait for the first server be ready - no CNI
Description Task 12: Wait for the first server to be ready by checking the node status using the kubectl command.

Task 13: Wait for the first server be ready - with CNI
Description Task 13: Wait for the first server to be ready by checking the node status using the kubectl command.

Task 14: Restore etcd
Description Task 14: Restore etcd by getting registered nodes, getting all node names, removing old node secrets, and removing old nodes.

Task 15: Set an Active Server variable
Description Task 15: Set the variable active_server to the inventory_hostname of the first server in the group rke2_cluster_group_name.
