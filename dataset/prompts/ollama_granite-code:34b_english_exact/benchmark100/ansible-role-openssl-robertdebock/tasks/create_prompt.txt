Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Create ssl key
Description Task 1: This task will create an ssl key using the openssl_privatekey module from the community.crypto collection. The key will be saved to the specified path with the specified mode, owner, and group.

Task 2: Create ssl csr
Description Task 2: This task will create an ssl csr using the openssl_csr module from the community.crypto collection. The csr will be saved to the specified path with the specified mode, owner, and group. The common name for the csr will be taken from the item.common_name variable.

Task 3: Create ssl certificates
Description Task 3: This task will create an ssl certificate using the x509_certificate module from the community.crypto collection. The certificate will be saved to the specified path with the specified mode, owner, and group. The private key and csr paths will be taken from the specified directories.

Task 4: Create PKCS#12 file
Description Task 4: This task will create a PKCS#12 file using the openssl_pkcs12 module from the community.crypto collection. The file will be saved to the specified path with the specified mode, owner, and group. The friendly name, private key, and certificate paths will be taken from the specified directories.

Task 5: Read private key
Description Task 5: This task will read the private key from the specified path using the slurp module from the ansible.builtin collection. The content of the private key will be registered as openssl_private_key.

Task 6: Read certificate
Description Task 6: This task will read the certificate from the specified path using the slurp module from the ansible.builtin collection. The content of the certificate will be registered as openssl_certifcate.

Task 7: Create combined private_key and certificate file
Description Task 7: This task will create a combined private_key and certificate file using the copy module from the ansible.builtin collection. The content of the file will be the content of the private key and the content of the certificate. The file will be saved to the specified path with the specified mode, owner, and group.
