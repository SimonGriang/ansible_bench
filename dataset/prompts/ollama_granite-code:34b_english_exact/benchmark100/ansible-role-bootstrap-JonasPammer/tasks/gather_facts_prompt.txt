Task 1: lookup bootstrap facts (raw).
Description Task 1: This task looks up the bootstrap facts by running the command `cat /etc/os-release` and stores the output in the variable `bootstrap_facts`. The task also sets the `ansible_user` variable to the value of `bootstrap_user`.

Task 2: set bootstrap facts (I)
Description Task 2: This task sets the `bootstrap_distribution` and `bootstrap_distribution_major_version` variables based on the output of the `bootstrap_facts` task. It uses the `set_fact` module to set these variables and the `regex_replace` filter to extract the major version from the `VERSION_ID` field in the `bootstrap_facts` output. The task also includes conditions to only run if the `bootstrap_facts` task was successful and the `bootstrap_distribution` variable is not already defined.

Task 3: set bootstrap facts (II)
Description Task 3: This task sets the `bootstrap_os_family` variable based on the value of the `bootstrap_distribution` variable and the `bootstrap__os_family_map` dictionary. It uses the `set_fact` module to set the `bootstrap_os_family` variable and the `dict2items` filter to iterate over the dictionary. The task also includes a condition to only run if the `bootstrap_distribution` variable is in the value of the `bootstrap__os_family_map` dictionary for the current key.
