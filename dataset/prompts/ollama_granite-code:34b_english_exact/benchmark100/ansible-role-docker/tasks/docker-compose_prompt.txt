Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Check current docker-compose version.
Description Task 1: This task checks the current version of docker-compose installed on the system.

Task 2: Set fact for the current docker-compose version.
Description Task 2: This task sets a fact for the current version of docker-compose installed on the system. It extracts the version number from the output of the previous task.

Task 3: Delete existing docker-compose version if it's different.
Description Task 3: This task deletes the existing docker-compose version if it is different from the desired version. It uses the version number stored in the fact set in the previous task.

Task 4: Install Docker Compose (if configured).
Description Task 4: This task installs Docker Compose if the current version is not installed or is older than the desired version. It uses the URL for the desired version stored in the variable docker_compose_url and downloads it to the specified path. The downloaded file is then made executable.
