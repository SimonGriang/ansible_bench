Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Import the assert.yml file as a task. Set run_once to true and delegate_to localhost.  

Task 2: Install fail2ban  
Description Task 2: Install the fail2ban package using the packages defined in the fail2ban_packages variable.  

Task 3: Copy filters in filter.d  
Description Task 3: Copy the fail2ban filters from the specified source directory to /etc/fail2ban/filter.d. Set owner to root, group to root, and mode to 0640. Only run if fail2ban_filterd_path is defined. Notify Restart fail2ban handler.  

Task 4: Configure fail2ban.local  
Description Task 4: Configure the fail2ban.local file by setting sections, options, and values from the fail2ban_base_configuration and fail2ban_configuration variables. Set mode to 0640. Notify Restart fail2ban handler. Use item.option as the label in the loop.  

Task 5: Configure jail.local  
Description Task 5: Configure the jail.local file by setting sections, options, and values from the fail2ban_base_jail_configuration and fail2ban_jail_configuration variables. Set mode to 0640. Notify Restart fail2ban handler. Use item.option as the label in the loop.  

Task 6: Stat auth log file  
Description Task 6: Check if the /var/log/auth.log file exists. Register the result to fail2ban_auth.  

Task 7: Touch auth log file  
Description Task 7: Create the /var/log/auth.log file if it does not exist. Set state to touch and mode to 0640. Only run if fail2ban_auth.stat.exists is not defined.  

Task 8: Start and enable fail2ban  
Description Task 8: Start the fail2ban service and enable it to start on boot. Use the fail2ban_service variable for the service name.
