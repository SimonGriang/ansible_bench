Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Remove old Docker versions.
Description Task 1: Uninstall obsolete Docker packages using the docker_obsolete_packages variable.

Task 2: Add Docker GPG key.
Description Task 2: Import the Docker GPG key from docker_yum_gpg_key when docker_add_repo is true.

Task 3: Add Docker repository.
Description Task 3: Download and add the Docker YUM repository file from docker_yum_repo_url to /etc/yum.repos.d/docker-{{ docker_edition }}.repo with proper ownership and permissions when docker_add_repo is true.

Task 4: Configure Docker Nightly repo.
Description Task 4: Enable or disable the Docker Nightly repository in /etc/yum.repos.d/docker-{{ docker_edition }}.repo using docker_yum_repo_enable_nightly when docker_add_repo is true.

Task 5: Configure Docker Test repo.
Description Task 5: Enable or disable the Docker Test repository in /etc/yum.repos.d/docker-{{ docker_edition }}.repo using docker_yum_repo_enable_test when docker_add_repo is true.

Task 6: Configure containerd on RHEL 8.
Description Task 6: Install and configure containerd on RHEL 8 systems by:
- Removing runc package
- Ensuring container-selinux is installed
- Ensuring containerd.io is installed
