Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Create directories
Description Task 1: Create directories for the HTTP server configuration. This task iterates over a list of directories defined in the httpd_directories variable and creates each directory with mode 0755.  

Task 2: Configure directories
Description Task 2: Configure HTTP server directories by creating configuration files from templates. This task uses a template file (directory.conf.j2) to generate configuration files in the HTTP server's configuration directory. Each configuration file is named based on the directory's name and has mode 0644. The task also notifies two handlers: "Test httpd configuration validity" and "Restart httpd" to ensure the configuration is valid and the service is restarted if necessary.
