Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the assert.yml file to include additional tasks and run it once on localhost.

Task 2: Install dns
Description Task 2: Install the DNS packages specified by the dns_packages variable.

Task 3: Create directories
Description Task 3: Create directories for DNS data and configuration with specified modes, owners, and groups.

Task 4: Create group
Description Task 4: Create the DNS group specified by the dns_group variable.

Task 5: Create user
Description Task 5: Create the DNS user specified by the dns_owner variable, marked as a system user.

Task 6: Generate rndc key
Description Task 6: Generate an rndc key file in the specified configuration directory.

Task 7: Set permissions on rndc key file
Description Task 7: Set the ownership and permissions of the rndc key file.

Task 8: Get the hints/root file
Description Task 8: Download the root hints file and set its permissions, conditional on dns_caching_dns being true.

Task 9: Create zone file
Description Task 9: Create DNS zone files from templates, validating each zone, and notify Rndc reload.

Task 10: Add zones to configuration
Description Task 10: Generate the main DNS configuration file and notify the Restart dns handler.

Task 11: Place systemd override
Description Task 11: Create systemd override configuration files and reload systemd, conditional on using systemd.

Task 12: Start and enable dns
Description Task 12: Start and enable the DNS service, ensuring it runs at boot.
