Task 1: Download RKE2 kubeconfig to localhost  
Description Task 1: Fetch the RKE2 configuration file from the server’s local path and copy it to a specified destination on the local machine. This task ensures the kubeconfig file is available for further processing.  

Task 2: Replace loopback IP by master server IP  
Description Task 2: Update the IP address in the downloaded kubeconfig file from the loopback interface to the master server’s IP. This ensures the kubeconfig points to the correct API server endpoint.
