Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Remove conflicting packages  
Description Task 1: Remove any packages that might conflict with the core dependencies being installed. This ensures a clean environment for the new packages to be installed without interference from older or conflicting versions.  

Task 2: Install packages  
Description Task 2: Install the core system packages required for the application to function properly. This includes essential utilities and libraries that are needed before proceeding with other configurations. The task also updates the package cache to ensure all dependencies are properly resolved.  

Task 3: Flush handlers  
Description Task 3: Flush any handlers that need to be executed after the tasks are completed. This ensures that any dependent tasks, such as gathering facts, are immediately triggered and run as part of the playbook execution flow.
