Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Import the assert.yml file to set up assertions for the role. This task runs once and delegates to localhost.  

Task 2: Wait for port to be available  
Description Task 2: Wait for the specified port to be available with a timeout defined by bootstrap_timeout. This task does not use become and runs only under specific connection conditions.  

Task 3: Prepare system  
Description Task 3: Prepare the system by testing the connection and sudo access. If these fail, gather facts and install necessary packages using raw commands. For RedHat systems, ensure libdnf5 is installed.  

Task 4: Gather ansible facts  
Description Task 4: Gather Ansible facts using the setup module without using become.  

Task 5: Install bootstrap packages (package)  
Description Task 5: Install packages listed in bootstrap_facts_packages variable using the package module, enabling privilege escalation based on bootstrap_become.
