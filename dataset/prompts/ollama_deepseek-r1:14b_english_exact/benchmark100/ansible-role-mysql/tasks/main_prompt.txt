Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the assert.yml tasks file to handle assertions and validations. This task runs once and delegates to localhost.

Task 2: Install mysql
Description Task 2: Install the MySQL packages specified in the mysql_packages variable. This task notifies the Set root password and Systemctl daemon-reexec handlers.

Task 3: Configure mysql server
Description Task 3: Configure the MySQL server by setting options in the configuration file. This task loops over mysql_configuration_options and notifies the Restart mysql server handler.

Task 4: Configure mysql client
Description Task 4: Configure the MySQL client by setting the socket path in the client configuration file.

Task 5: Initialize mysql
Description Task 5: Initialize MySQL, but only if the distribution is Alpine or Archlinux.

Task 6: Start and enable mysql
Description Task 6: Start and enable the MySQL service to ensure it runs on boot.

Task 7: Place my.cnf
Description Task 7: Place a my.cnf file using a template, setting the appropriate mode.

Task 8: Create databases
Description Task 8: Create databases based on the mysql_databases variable. This task is skipped if mysql_databases is not defined.

Task 9: Create users
Description Task 9: Create MySQL users with specified privileges, based on the mysql_users variable. This task is skipped if mysql_users is not defined.

Task 10: Flush handlers again
Description Task 10: Flush handlers to ensure all changes are applied.
