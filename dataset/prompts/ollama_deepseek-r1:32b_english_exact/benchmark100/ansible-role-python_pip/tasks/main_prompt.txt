Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Import the assertion tasks file to perform prerequisite checks.

Task 2: Install python pip  
Description Task 2: Install Python pip packages specified in the variable python_pip_packages.

Task 3: Configure pip proxy  
Description Task 3: Configure the pip proxy settings by setting the index-url in /etc/pip.conf using the variable python_pip_proxy. This task runs only when python_pip_proxy is defined.

Task 4: Trust hosts  
Description Task 4: Configure trusted hosts for pip by setting the trusted-host in /etc/pip.conf using the variable python_pip_trusted_host. This task runs only when python_pip_trusted_host is defined.

Task 5: Update pip.  
Description Task 5: Update pip to the specified version or state using the variable python_pip_pip_package and python_pip_pip_state. This task uses the executable specified in python_pip_executable and runs only when python_pip_update is true and the OS is not bookworm, noble, or Alpine.

Task 6: Install requested modules  
Description Task 6: Install Python packages specified in the python_pip_modules list. Each module's name, state, and version are specified in the list. This task runs only when the OS is not bookworm, noble, or Alpine.
