Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Import the assert.yml file to run assertion tasks, execute once on localhost.  

Task 2: Install php  
Description Task 2: Install PHP packages using the list defined in the php_packages variable.  

Task 3: Find used php.ini  
Description Task 3: Execute a shell command to determine the location of the php.ini file, store the result in php_found_ini_location, and only run if php_ini_location is not already defined.  

Task 4: Configure php  
Description Task 4: Use a template to configure PHP settings, write to the php.ini file located at php_ini_location or the found location, set file permissions to 0644, and notify the Restart httpd handler.
