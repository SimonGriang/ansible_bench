Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Import the assert.yml tasks file to execute additional setup validations. This task is run once and delegated to localhost.

Task 2: Install required packages  
Description Task 2: Install system packages listed in the service_required_packages variable. This task notifies the Gather facts handler after completion.

Task 3: Configure systemd service  
Description Task 3: Configure systemd service files using the systemd.j2 template for each service in the service_list. This task is only executed when the system uses systemd as the service manager and notifies the Systemctl daemon-reload handler.

Task 4: Configure sysvinit service  
Description Task 4: Configure sysvinit service files using the sysvinit.j2 template for each service in the service_list. This task is executed when the system uses sysvinit, upstart, or openrc as the service manager.

Task 5: Manage service  
Description Task 5: Manage the state and enablement of services using the service module for each service in the service_list. This task is only executed when either the state or enabled parameters are defined for a service.

Task 6: Flush handlers  
Description Task 6: Flush all pending handlers to ensure all notifications are processed immediately.
