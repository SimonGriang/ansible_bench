Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Assert usage of systemd as an init system  
Description Task 1: Check if the system uses systemd as the init system and fail with a message if not.

Task 2: Get latest release  
Description Task 2: Fetch the latest release information from the Grafana Loki GitHub repository using the API. Retry up to 5 times if the initial request fails. The request is made with optional GitHub credentials from environment variables and the response is stored in the _latest_release variable.

Task 3: Set promtail version to latest  
Description Task 3: Set the promtail_version variable to the latest release tag from the GitHub API response, removing the leading 'v' from the tag name.

Task 4: Test if zip local archive exists  
Description Task 4: Check if a local Promtail binary archive exists at the specified path using the stat module. The result is stored in promtail_binary_local_archive.

Task 5: Assert local binary exists  
Description Task 5: Assert that the local Promtail binary archive exists, failing with a specific message if it does not.

Task 6: Get checksum list  
Description Task 6: Retrieve the list of checksums from the GitHub release page for the specified promtail_version and store them in __promtail_checksums.

Task 7: Get checksum for {{ go_arch }} architecture  
Description Task 7: Extract the checksum for the Promtail binary corresponding to the current architecture (go_arch) from the list of checksums and store it in __promtail_checksum.
