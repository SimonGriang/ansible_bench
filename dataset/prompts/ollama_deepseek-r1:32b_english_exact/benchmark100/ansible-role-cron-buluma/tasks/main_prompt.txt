Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Import the assert.yml tasks file to perform prerequisite checks or assertions before proceeding with the main tasks. This is done once and delegated to localhost.

Task 2: Install cron  
Description Task 2: Install the cron package using the package module. The package name is specified by the variable cron_packages, and the state is set to present to ensure it is installed.

Task 3: Configure shell  
Description Task 3: Configure the SHELL variable in the cron configuration file located at cron_configuration. The value is set to cron_shell, and the file is created if it doesn't exist with mode 0600. This task notifies the Restart cron handler.

Task 4: Configure path  
Description Task 4: Configure the PATH variable in the cron configuration file. The value is set to cron_path, and the file is created if necessary with mode 0600. This task also notifies the Restart cron handler.

Task 5: Configure mailto  
Description Task 5: Configure the MAILTO variable in the cron configuration file. The value is set to cron_mailto, and the file is created if it doesn't exist with mode 0600. This task notifies the Restart cron handler.

Task 6: Start and enable cron  
Description Task 6: Start the cron service and enable it to start on boot. The service name is specified by cron_service, and this task is only executed if cron_service is defined and not empty.

Task 7: Schedule requested cron jobs  
Description Task 7: Schedule cron jobs based on the list provided in cron_jobs. Each job specifies details like name, time fields (minute, hour, etc.), job command, state, and user. The loop iterates over each job, using item.name as the label for better readability in the output. This task is only executed if cron_jobs is defined.
