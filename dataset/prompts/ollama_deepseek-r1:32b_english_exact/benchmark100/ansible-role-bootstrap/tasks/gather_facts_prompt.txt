The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: gather_facts | Lookup bootstrap facts  
Description Task 1: Execute a raw command to gather OS release information by reading the /etc/os-release file and store the output in the bootstrap_facts variable.  

Task 2: gather_facts | Set bootstrap facts (I)  
Description Task 2: Set facts for the bootstrap_distribution and bootstrap_distribution_major_version by parsing the bootstrap_facts variable. The major version is extracted using a regular expression and defaults to 'NA' if not found.  

Task 3: gather_facts | Set bootstrap facts (II)  
Description Task 3: Map the detected bootstrap_distribution to an OS family by iterating through the bootstrap_os_family_map dictionary and setting the bootstrap_os_family fact accordingly.
