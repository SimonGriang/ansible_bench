Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Imports the assertion tasks file from assert.yml, runs once on localhost.

Task 2: Install prerequisites  
Description Task 2: Installs the required packages specified in the vault_prerequisites variable.

Task 3: Include installation method specific tasks  
Description Task 3: Includes tasks from a file named after the vault_installation_method variable, e.g., vault_installation_method.yml.

Task 4: Add Vault environment variables  
Description Task 4: Adds environment variables to /etc/vault.d/vault.env file using the vault_environment_settings variable, ensuring proper permissions and notifying a restart handler.

Task 5: Include hardening tasks  
Description Task 5: Includes security hardening tasks from the hardening.yml file.

Task 6: Start and enable vault  
Description Task 6: Starts and enables the vault service if vault_type is set to "oss".

Task 7: Enable vault  
Description Task 7: Enables the vault service if vault_type is not set to "oss".
