Task 2: Disable core dumps
Description Task 2: Configure PAM limits to disable core dumps for all users by setting both hard and soft core limits to 0.

Task 3: Disable Shell Command History
Description Task 3: Configure the shell to ignore vault-related commands in the command history by creating a profile script (/etc/profile.d/vault.sh) with HISTIGNORE set to vault*.

Task 4: Configure SELinux and AppArmor
Description Task 4: Enable and configure SELinux by installing selinux-policy and setting the policy to targeted enforcing mode. Additionally, enable AppArmor enforcing for the vault binary if AppArmor is enabled.
