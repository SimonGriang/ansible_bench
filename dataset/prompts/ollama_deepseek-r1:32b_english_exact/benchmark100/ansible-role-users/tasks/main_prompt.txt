Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Imports the assert.yml file to perform assertion checks, ensuring the environment meets the required conditions. This task runs once and delegates execution to localhost.  

Task 2: Install required software  
Description Task 2: Installs the software packages listed in the users_requirements variable if the list is not empty. Uses the package module to manage the installation.  

Task 3: Loop over users_groups  
Description Task 3: Iterates over each group in the users_groups list and includes the group.yml file to create or modify system groups. Uses group.name as the loop label and group as the loop variable.  

Task 4: Ensure the /etc/sudoers.d directory is included  
Description Task 4: Modifies the /etc/sudoers file to include the /etc/sudoers.d directory by adding the specified line. Uses the lineinfile module with a regular expression to ensure proper placement and validates changes with visudo.  

Task 5: Loop over users  
Description Task 5: Iterates over each user in the users list and includes the user.yml file to create or modify user accounts. Uses user.name as the loop label and user as the loop variable.  

Task 6: Manage cron permission  
Description Task 6: Manages cron permissions by creating or updating the /etc/cron.allow file using a template. The template is sourced from cron.allow.j2 and sets the file mode to 0644.  

Task 7: Check existence of /etc/cron.allow  
Description Task 7: Checks if the /etc/cron.allow file exists and removes it if the users_cron_allow variable is not set to true. Uses the file module to ensure the file is absent when needed.
