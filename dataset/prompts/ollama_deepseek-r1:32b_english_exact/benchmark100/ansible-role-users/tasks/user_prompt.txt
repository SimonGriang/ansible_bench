Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Create a local SSH key directory for a user  
Description Task 1: Create a directory for storing SSH keys for the specified user with mode 0750, only when user.manage_ssh_key is defined and true.  

Task 2: Manage user account  
Description Task 2: Create or modify a user account with various attributes including name, state, comment, home directory, password, UID, GID, shell, and expiration.  

Task 3: Set sudo options for user  
Description Task 3: Generate sudo configuration file from a template and place it in /etc/sudoers.d/ for the specified user when user.sudo_options is defined.  

Task 4: Remove sudo options for user  
Description Task 4: Remove sudo configuration file for the specified user when user.sudo_options is not defined.  

Task 5: Generate private SSH key for user  
Description Task 5: Generate a private SSH key for the specified user using a command and store it in the SSH key directory when user.manage_ssh_key is defined and true.  

Task 6: Generate public SSH key for user  
Description Task 6: Generate a public SSH key for the specified user using a shell command and store it in the SSH key directory when user.manage_ssh_key is defined and true.  

Task 7: Convert SSH key to PPK format for user  
Description Task 7: Convert the private SSH key to PPK format for the specified user using ssh-keygen and store it in the SSH key directory when user.manage_ssh_key is defined and true.  

Task 8: Get or set the home directory for user  
Description Task 8: Retrieve the home directory of the specified user using getent, or set it to /home if the user does not exist.  

Task 9: Create .ssh directory for user  
Description Task 9: Create .ssh directory in the user's home directory with mode 700 when managing SSH keys or when private_keys are defined.  

Task 10: Deploy authorized SSH keys for user  
Description Task 10: Add specified authorized SSH keys to the user's .ssh/authorized_keys file.  

Task 11: Remove unauthorized SSH keys for user  
Description Task 11: Remove specified unauthorized SSH keys from the user's .ssh/authorized_keys file.  

Task 12: Copy generated private SSH key to user's home  
Description Task 12: Copy the generated private SSH key to the user's .ssh directory when user.copy_private_key is defined and true.  

Task 13: Check user's password validity  
Description Task 13: Check the validity period of the user's password using chage and store the result.  

Task 14: Set user's password validity  
Description Task 14: Set the maximum password validity period for the user using chage when the specified password_validity_days differs from the current value.  

Task 15: Place private key files for user  
Description Task 15: Copy private key files to the user's .ssh directory from a list of specified keys.
