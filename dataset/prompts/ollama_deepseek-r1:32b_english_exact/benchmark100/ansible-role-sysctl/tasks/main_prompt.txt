Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the assert.yml tasks file to perform prerequisite checks or assertions before proceeding with other tasks. This task runs once and is delegated to localhost.

Task 2: Install requirements
Description Task 2: Install the required packages specified in the sysctl_requirements variable using the package module to ensure all dependencies are met for sysctl configuration.

Task 3: Set sysctl setting
Description Task 3: Configure sysctl settings by iterating over the sysctl_items list. For each item, set the sysctl parameter using the name and value from the item. Apply the configuration only if sysctl_items, item.name, and item.value are defined, and the connection type is not container, docker, or community.docker.docker. Use the sysctl_set and sysctl_reload variables to control how the settings are applied.
