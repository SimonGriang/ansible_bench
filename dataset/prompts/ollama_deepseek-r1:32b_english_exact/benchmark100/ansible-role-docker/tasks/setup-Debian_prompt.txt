Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Ensure apt key is not present in trusted.gpg.d  
Description Task 1: Remove the Docker apt key from the trusted.gpg.d directory if it exists. This ensures there are no leftover keys that could cause conflicts during the installation process.

Task 2: Ensure old apt source list is not present in /etc/apt/sources.list.d  
Description Task 2: Remove the old Docker apt source list file if it exists. The file path includes the distribution name in lowercase to match the appropriate file for the system's operating system.

Task 3: Ensure old versions of Docker are not installed  
Description Task 3: Uninstall any obsolete Docker packages that may be present on the system. This step is necessary to avoid conflicts with the new Docker installation.

Task 4: Ensure legacy repo file is not present  
Description Task 4: Remove the legacy Docker repository file from the sources.list.d directory if it exists. This ensures that the system uses the correct repository for Docker installation.

Task 5: Ensure dependencies are installed  
Description Task 5: Install the required dependencies for Docker, including apt-transport-https, ca-certificates, and python3-debian. These packages are necessary for Docker to function properly.

Task 6: Add or remove Docker repository  
Description Task 6: Add or remove the Docker apt repository based on the value of the docker_add_repo variable. The repository configuration includes the repository name, URL, distribution, release channel, and GPG key for verification. If the repository should be removed, it will be removed instead.

Task 7: Ensure handlers are notified immediately to update the apt cache  
Description Task 7: Flush any pending handlers to ensure that the apt cache is updated immediately. This ensures that any changes to the repositories or packages are reflected in the system's package manager before proceeding further.
