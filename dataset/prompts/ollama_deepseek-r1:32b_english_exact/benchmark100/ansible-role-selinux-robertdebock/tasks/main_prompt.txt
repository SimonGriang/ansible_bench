Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the assert.yml tasks file once and delegate it to localhost.

Task 2: Install required packages
Description Task 2: Install the packages listed in the selinux_requirements variable using the package module and set their state to present. Notify the Gather facts handler after installation.

Task 3: Flush handlers
Description Task 3: Flush all pending handlers to ensure they are executed immediately.

Task 4: Configure selinux
Description Task 4: Configure SELinux based on the selinux_state and selinux_policy variables. If selinux_booleans is defined, configure each SELinux boolean using the seboolean module with the specified state and persistence. Only execute this task if the selinux.status fact is defined and the connection type is not container, docker, or community.docker.docker.
