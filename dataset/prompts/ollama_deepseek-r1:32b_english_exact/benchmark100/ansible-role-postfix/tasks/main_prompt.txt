Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Import the assert.yml file to execute additional tasks defined in that file.

Task 2: Pre-configure debian systems  
Description Task 2: Configure debconf settings for postfix on Debian systems to set the main_mailer_type to "No configuration".

Task 3: Install postfix  
Description Task 3: Install the postfix package on the system.

Task 4: Install postfix-mysql  
Description Task 4: Install the postfix-mysql package if specific postfix virtual mailbox or alias map configurations use mysql.

Task 5: Configure postfix (transport_maps)  
Description Task 5: Configure postfix transport maps by rendering a template to /etc/postfix/transport and notifying handlers to validate and rebuild the transport_maps database.

Task 6: Configure postfix (header_checks)  
Description Task 6: Configure postfix header checks by rendering a template to /etc/postfix/header_checks and notifying handlers to validate and reload postfix.

Task 7: Setting values for main.cf (1/2)  
Description Task 7: Set facts for postfix smtpd recipient and sender restrictions based on defined variables.

Task 8: Setting values for main.cf (2/2)  
Description Task 8: Set facts for various postfix main.cf configuration parameters including mynetworks, mydestination, relay domains, virtual mailbox domains, and virtual alias domains.

Task 9: Configure postfix (main.cf)  
Description Task 9: Configure postfix main.cf by rendering a template to /etc/postfix/main.cf with validation and notifying handlers to validate and restart postfix.

Task 10: Configure postfix (master.cf)  
Description Task 10: Configure postfix master.cf by rendering a template to /etc/postfix/master.cf with validation and notifying handlers to validate and restart postfix.

Task 11: Creates cert/key directory  
Description Task 11: Create directories for postfix TLS certificate and key files if specific variables are defined.

Task 12: Deploy Postfix TLS server certificate  
Description Task 12: Deploy the postfix TLS server certificate from a specified source to the destination file and notify postfix to reload.

Task 13: Deploy Postfix TLS server key  
Description Task 13: Deploy the postfix TLS server key from a specified source to the destination file and notify postfix to reload.

Task 14: Flush handlers  
Description Task 14: Flush all pending handlers to execute their tasks.

Task 15: Configure aliases  
Description Task 15: Configure postfix aliases by adding entries to the alias file and notifying handlers to rebuild the alias database and reload postfix.

Task 16: Configure sender_access  
Description Task 16: Configure postfix sender_access by adding entries to the sender_access file and notifying handlers to rebuild the sender_access database and reload postfix.

Task 17: Configure recipient_access  
Description Task 17: Configure postfix recipient_access by adding entries to the recipient_access file and notifying handlers to validate, rebuild the recipient_access database, and reload postfix.

Task 18: Place sasl_password_map  
Description Task 18: Deploy the sasl_password_map file with specified content and notify handlers to rebuild the sasl_password_map database.

Task 19: Flush handlers again  
Description Task 19: Flush all pending handlers again to ensure all tasks are executed.

Task 20: Start and enable postfix  
Description Task 20: Start the postfix service and enable it to start on boot.
