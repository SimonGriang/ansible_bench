Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: check if all variables have been set correctly
Description Task 1: Import tasks to assert that all required variables have been set correctly and run this check once on localhost.

Task 2: wait for host (when configured)
Description Task 2: Wait for the host to become reachable on the specified port with a configurable timeout, using the local connection and optional become privileges, but only when the connection type is not container-related and bootstrap_wait_for_host is enabled.

Task 3: prepare system
Description Task 3: Test the connection to the host with a specified timeout. If the connection fails, log a note with the timeout value. Regardless of success or failure, include tasks to gather bootstrap facts (raw) and install bootstrap packages using a raw command, which may vary based on the OS family (Alpine, Archlinux, Gentoo, Debian, RedHat, Rocky, or Suse).

Task 4: ensure system is prepared by issuing ansible modules.
Description Task 4: Gather Ansible facts and install bootstrap packages using the package module, looping over the list of packages specified in bootstrap__facts_packages, with optional become privileges.
