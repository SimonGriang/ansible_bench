Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Import the assertion tasks file to perform prerequisite checks before proceeding with OpenVPN setup.  

Task 2: Install openvpn packages  
Description Task 2: Install the OpenVPN packages specified in the variable `openvpn_packages` to ensure the required software is present.  

Task 3: Setup openvpn server or client  
Description Task 3: Include tasks from either `server.yml` or `client.yml` based on the value of the variable `openvpn_role` to configure the OpenVPN instance as either a server or a client.  

Task 4: Start and enable openvpn  
Description Task 4: Start the OpenVPN service and ensure it is enabled to start automatically on boot using the service name specified in the variable `openvpn_service`.
