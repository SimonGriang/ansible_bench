Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Create SSL key  
Description Task 1: Create an OpenSSL private key with specified permissions, owner, and group, stored in a directory defined by openssl_key_directory.

Task 2: Create SSL CSR  
Description Task 2: Generate an OpenSSL Certificate Signing Request (CSR) using the previously created private key, with common name specified by item.common_name, and stored in a directory defined by openssl_csr_directory.

Task 3: Create SSL certificates  
Description Task 3: Generate an OpenSSL X.509 certificate using the private key and CSR, signed by a self-signed authority, stored in a directory defined by openssl_crt_directory.

Task 4: Create PKCS#12 file  
Description Task 4: Export the private key and certificate into a PKCS#12 file with a friendly name, stored in the private key directory.

Task 5: Read private key  
Description Task 5: Read the contents of the private key file and store it in a variable for later use.

Task 6: Read certificate  
Description Task 6: Read the contents of the certificate file and store it in a variable for later use.

Task 7: Create combined private_key and certificate file  
Description Task 7: Combine the private key and certificate contents into a single file with .keycrt extension, stored in the private key directory, with specified permissions, owner, and group.
