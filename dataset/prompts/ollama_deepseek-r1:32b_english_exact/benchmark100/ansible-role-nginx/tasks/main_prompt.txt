Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Imports the assert.yml task file, runs once, and delegates execution to localhost.

Task 2: Install nginx  
Description Task 2: Installs the nginx package using the package module with state set to present.

Task 3: Place nginx.conf  
Description Task 3: Creates the nginx.conf file from the nginx.conf.j2 template, validates the configuration using nginx -t -c, sets the mode to 0644, and notifies the Restart nginx handler.

Task 4: Ensure /etc/nginx/conf.d exists  
Description Task 4: Creates the /etc/nginx/conf.d directory if it does not exist, sets the mode to 0755.

Task 5: Place default.conf  
Description Task 5: Creates the default.conf file from the default.conf.j2 template, sets the mode to 0644, and notifies the Restart nginx handler.

Task 6: Start and enable nginx  
Description Task 6: Starts the nginx service and enables it to start on boot using the service module.
