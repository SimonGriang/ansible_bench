Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: create | Create ssl key  
Description Task 1: Create an SSL private key file with specified permissions, owner, and group using the community.crypto.openssl_privatekey module. The key is saved to a directory specified by openssl_key_directory with the filename derived from item.name.

Task 2: create | Create ssl csr  
Description Task 2: Generate an SSL Certificate Signing Request (CSR) using the community.crypto.openssl_csr module. The CSR is saved to a directory specified by openssl_csr_directory with the filename derived from item.name. The private key path is sourced from the previously created key file.

Task 3: create | Create ssl certificates  
Description Task 3: Generate an SSL certificate using the community.crypto.x509_certificate module. The certificate is self-signed and saved to a directory specified by openssl_crt_directory with the filename derived from item.name. The private key and CSR paths are sourced from the previously created files.

Task 4: create | Create PKCS#12 file  
Description Task 4: Create a PKCS#12 file using the community.crypto.openssl_pkcs12 module. The file is saved to a directory specified by openssl_key_directory with the filename derived from item.name. The friendly name is set to item.name, and the private key and certificate paths are sourced from the previously created files.

Task 5: create | Read private key  
Description Task 5: Read the contents of the private key file using the ansible.builtin.slurp module. The file path is sourced from the previously created key file, and the content is registered for later use.

Task 6: create | Read certificate  
Description Task 6: Read the contents of the SSL certificate file using the ansible.builtin.slurp module. The file path is sourced from the previously created certificate file, and the content is registered for later use.

Task 7: create | Create combined private_key and certificate file  
Description Task 7: Combine the private key and certificate contents into a single file using the ansible.builtin.copy module. The combined content is written to a file saved to a directory specified by openssl_key_directory with the filename derived from item.name. The file permissions, owner, and group are set as specified.
