Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assertion tasks  
Description Task 1: Import the assertion tasks file to perform prerequisite checks before proceeding with the main tasks.

Task 2: Uninstall conflicting systemd-logger  
Description Task 2: Remove the systemd-logger package to prevent conflicts with rsyslog.

Task 3: Install rsyslog  
Description Task 3: Install the rsyslog package using the package names specified in the variable rsyslog_packages with the state defined in rsyslog_package_state.

Task 4: Install additional rsyslog packages  
Description Task 4: Install extra rsyslog packages based on the list defined in rsyslog_features, using the package state specified in rsyslog_package_state.

Task 5: Configure default rsyslog  
Description Task 5: Configure the default rsyslog settings by templating the configuration file from the specified template file format to the destination configuration file location, with appropriate permissions.

Task 6: Create rsyslog configuration directory  
Description Task 6: Ensure the /etc/rsyslog.d/ directory exists with the correct permissions (0755).

Task 7: Configure rsyslog forward rule  
Description Task 7: Configure the rsyslog forward rule by templating the forward rule configuration file to the specified destination in /etc/rsyslog.d/, with appropriate permissions, but only if rsyslog_deploy_default_config is false.

Task 8: Configure additional rsyslog files  
Description Task 8: Copy additional rsyslog configuration files from the dictionary defined in rsyslog_rsyslog_d_files to the /etc/rsyslog.d/ directory, with specified content, owner, group, and permissions, and only if the state of the item is 'present'.

Task 9: Start and enable rsyslog service  
Description Task 9: Start the rsyslog service and enable it to start at boot, using the service name specified in rsyslog_service.
