Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Imports the assert.yml file to perform prerequisite checks for the DNS setup. This task is run once and delegated to localhost.

Task 2: Install dns  
Description Task 2: Installs the DNS server packages specified in the variable dns_packages.

Task 3: Create directories  
Description Task 3: Creates necessary directories for DNS data and configuration, with specific modes, owners, and groups. The directories are {{ dns_datadir }} and {{ dns_confdir }}.

Task 4: Create group  
Description Task 4: Creates the system group specified in the variable dns_group.

Task 5: Create user  
Description Task 5: Creates the system user specified in the variable dns_owner with system: true.

Task 6: Generate rndc key  
Description Task 6: Generates the rndc key file at {{ dns_confdir }}/rndc.key using rndc-confgen.

Task 7: Set permissions on rndc key file  
Description Task 7: Sets the permissions, owner, and group for the rndc key file to 0640, {{ dns_owner }}, and {{ dns_group }}.

Task 8: Get the hints/root file  
Description Task 8: Downloads the named.root file from https://www.internic.net/domain/named.root to {{ dns_datadir }}/named.root if caching DNS is enabled.

Task 9: Create zone file  
Description Task 9: Generates zone files from the zone.j2 template for each zone in dns_zones that is either primary or has an undefined type.

Task 10: Add zones to configuration  
Description Task 10: Generates the named.conf configuration file from the named.conf.j2 template, validates it, and backs up the existing file.

Task 11: Place systemd override  
Description Task 11: Creates a systemd override directory and places override.conf in it if the service manager is systemd.

Task 12: Start and enable dns  
Description Task 12: Starts and enables the DNS service specified in dns_service.
