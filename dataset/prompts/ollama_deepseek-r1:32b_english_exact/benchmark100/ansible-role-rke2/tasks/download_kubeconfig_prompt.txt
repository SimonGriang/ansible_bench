Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Download RKE2 kubeconfig to localhost  
Description Task 1: Download the RKE2 kubeconfig file from the remote server to the local machine. The file is fetched from /etc/rancher/rke2/rke2.yaml and saved to the specified path with the given filename. The flat option is set to yes to avoid creating nested directories. This task is conditional based on the value of rke2_download_kubeconf and only runs on the first node in the rke2_servers_group.  

Task 2: Replace loopback IP by master server IP  
Description Task 2: Replace the loopback IP addresses (127.0.0.1 and ::1) in the downloaded kubeconfig file with the master server's IP address. The file is modified in-place with appropriate permissions, and the task is delegated to localhost to ensure it runs on the control node. The replacement IP is determined by the rke2_api_ip variable or falls back to the ansible_host of the first node in the rke2_servers_group. This task is skipped in check mode and conditional based on the value of rke2_download_kubeconf.
