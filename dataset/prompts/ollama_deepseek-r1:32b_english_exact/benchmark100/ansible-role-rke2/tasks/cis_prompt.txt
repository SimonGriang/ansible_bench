Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Create etcd group  
Description Task 1: Create the 'etcd' group using the ansible.builtin.group module with state set to present.  

Task 2: Create etcd user  
Description Task 2: Create the 'etcd' user using the ansible.builtin.user module with shell set to /bin/nologin, group set to etcd, comment set to etcd user, and state set to present.  

Task 3: Copy systemctl config file for kernel hardening  
Description Task 3: Copy the kernel hardening configuration file to /etc/sysctl.d/60-rke2-cis.conf using the ansible.builtin.copy module. The source path is determined conditionally based on whether the directory is writable or if the partition check failed, and the file is copied with mode 0600 and remote_src set to true. This task notifies the Restart systemd-sysctl handler.  

Task 4: Flush handlers  
Description Task 4: Flush all pending handlers using the ansible.builtin.meta module with the flush_handlers action.
