Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import assert.yml file for validation purposes, ensuring tasks are only executed once by delegating to localhost.

Task 2: Wait for port to be available
Description Task 2: Wait for a specified port to become available, using a timeout value defined in the variable bootstrap_timeout. This task ensures the playbook does not proceed before the connection is up and running.

Task 3: Prepare system
Description Task 3: Prepare the system by testing the connection and sudo availability without using 'become' as python and sudo might not be installed yet. If issues arise, gather bootstrap facts and install necessary packages using the raw module.

Task 4: Gather ansible facts
Description Task 4: Gather facts about the system using the setup module. This helps in understanding the current state of the system before proceeding with further tasks.

Task 5: Install bootstrap packages (package)
Description Task 5: Install a list of packages specified in the bootstrap_facts_packages variable. This task uses the package module and updates the cache to ensure the latest package information is used.
