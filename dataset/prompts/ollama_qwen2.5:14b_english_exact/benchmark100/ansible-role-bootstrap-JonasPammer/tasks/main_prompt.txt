Below you will receive task descriptions from which you should generate an Ansible Playbook.
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

Task 1: check if all variables have been set correctly
Description Task 1: Assert that all required variables are set correctly before proceeding with the playbook tasks.

Task 2: wait for host (when configured)
Description Task 2: Wait for the host to become available on a specific port and with the correct hostname. This task is optional and is only executed if the variable bootstrap_wait_for_host is set to true.

Task 3: prepare system
Description Task 3: Prepare the system by establishing a connection to the host and gathering facts. If the connection cannot be established, a debug message will be displayed.

Task 4: include tasks to gather bootstrap facts (raw)
Description Task 4: Include a task file to gather raw bootstrap facts. This is included as part of the prepare system block.

Task 5: Install bootstrap packages (raw).
Description Task 5: Install bootstrap packages using a raw command. This task is executed based on the operating system family and the bootstrap_install.raw variable.

Task 6: ensure system is prepared by issuing ansible modules.
Description Task 6: Ensure the system is prepared by gathering ansible facts and installing bootstrap packages using the ansible package module. This task uses the bootstrap facts to determine which packages to install.
