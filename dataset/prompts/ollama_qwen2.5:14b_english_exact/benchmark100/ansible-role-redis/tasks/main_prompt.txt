The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

Task 2: Enable redis module stream (RHEL 8)

Task 3: Install redis

Task 4: Configure redis
Description Task 4: Configure redis by templating a redis.conf file based on the distribution type, placing it in the appropriate directory with specific ownership, group, and mode permissions. The task will notify a handler to restart the redis service upon configuration changes.

Task 5: Start and enable redis
Description Task 5: Start the redis service and ensure it is enabled to start on boot using the variable `redis_service`.
