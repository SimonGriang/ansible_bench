Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the assert.yml file to perform initial validation and run it only on the localhost.

Task 2: Install apache httpd
Description Task 2: Install the Apache HTTPD package with the name defined in the variable `httpd_packages`.

Task 3: Configure selinux
Description Task 3: Configure SELinux settings if it is enabled, and allow connections to custom HTTP and HTTPS ports.

Task 4: Configure httpd
Description Task 4: Configure the Apache HTTPD server by templating the configuration file from `httpd_config_src` to `httpd_config_dest` and notifying handlers for testing configuration validity and restarting the service.

Task 5: Activate httpd module | Debian

Task 6: Import ssl.yml
Description Task 6: Import the ssl.yml file to configure SSL settings if `https_ssl_enable` is true.

Task 7: Import locations.yml
Description Task 7: Import the locations.yml file to configure Apache locations if `httpd_locations` is defined.

Task 8: Import vhosts.yml
Description Task 8: Import the vhosts.yml file to configure Apache virtual hosts if `httpd_vhosts` is defined.

Task 9: Configure ports
Description Task 9: Configure ports for Apache if the operating system is Debian or Suse by templating the configuration file and notifying handlers for testing configuration validity and restarting the service.

Task 10: Import directories.yml
Description Task 10: Import the directories.yml file to configure directories if `httpd_directories` is defined.

Task 11: Flush handlers
Description Task 11: Flush all handlers to ensure they are executed.

Task 12: Removing default html
Description Task 12: Remove the default index.html file from the HTTPD data directory if `httpd_remove_example` is true.

Task 13: Start and enable httpd
