Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the assert.yml file to handle assertions for the role. The task should run only once and be delegated to localhost.

Task 2: Install nginx
Description Task 2: Install the nginx package on the target system.

Task 3: Place nginx.conf
Description Task 3: Copy the nginx configuration file from a template to the /etc/nginx/nginx.conf location with specific file permissions. The task should notify a handler to restart nginx after the file is placed.

Task 4: Ensure /etc/nginx/conf.d exists
Description Task 4: Ensure the directory /etc/nginx/conf.d exists and has the correct permissions.

Task 5: Place default.conf
Description Task 5: Copy the default configuration file from a template to the /etc/nginx/conf.d/default.conf location with specific file permissions. The task should notify a handler to restart nginx after the file is placed.

Task 6: Start and enable nginx
Description Task 6: Start the nginx service and ensure it is enabled to start on boot.
