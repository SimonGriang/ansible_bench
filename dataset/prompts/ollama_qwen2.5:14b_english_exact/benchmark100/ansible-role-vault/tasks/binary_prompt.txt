Below you will receive task descriptions from which you should generate an Ansible Playbook.
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

Task 2: Create Vault user

Task 3: Create Vault download directory
Description Task 3: Create a directory at {{ vault_download_path }} with permissions set to 0755 and owned by the {{ vault_user }} user and {{ vault_group }} group.

Task 4: Download Vault binary
Description Task 4: Download the Vault binary from the specified URL and unarchive it to {{ vault_download_path }}. Ensure the file is owned by root.

Task 5: Check if vault_path exists

Task 6: Create vault_path if it does not exist
Description Task 6: If the directory at {{ vault_path }} does not exist and is specified, create it with permissions set to 0755 and owned by the {{ vault_user }} user and {{ vault_group }} group.

Description Task 7: Create directories specified in the vault_directories list with permissions set to 0755 and owned by the specified owner and group.

Task 15: Copy Vault service file
Description Task 15: Copy the Vault service file template vault.service.j2 to /usr/lib/systemd/system/vault.service with permissions set to 0644 and notify the handler 'Daemon reload' after completion only if the service manager is systemd.

Task 16: Copy vault configuration
Description Task 16: Copy the vault configuration file vault.hcl to {{ vault_path }}/etc/vault.d/vault.hcl with permissions set to 0644 and notify the handler 'Restart vault' after completion.

Task 17: Flush handlers
Description Task 17: Flush all the handlers in the playbook.
