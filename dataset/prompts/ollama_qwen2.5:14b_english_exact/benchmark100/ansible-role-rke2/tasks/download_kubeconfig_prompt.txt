Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Download RKE2 kubeconfig to localhost
Description Task 1: Download the RKE2 kubeconfig file from the remote server to the local machine based on the provided variables. The source file is located at /etc/rancher/rke2/rke2.yaml on the remote server and is fetched to the path defined by the variable `rke2_download_kubeconf_path` with the filename `rke2_download_kubeconf_file_name`. This task is conditional based on the variable `rke2_download_kubeconf` being true and the inventory_hostname matching the first host in the group `rke2_servers_group_name`.

Task 2: Replace loopback IP by master server IP
Description Task 2: Replace occurrences of loopback IP addresses (127.0.0.1 and ::1) in the downloaded kubeconfig file with the IP address of the master server. The IP address is retrieved using the variable `rke2_api_ip` or falls back to the primary IP of the first host in the `rke2_servers_group_name` group if `rke2_api_ip` is not defined. This task is executed on the localhost and is conditional based on the playbook not being in check mode, `rke2_download_kubeconf` being true, and the inventory_hostname matching the first host in the `rke2_servers_group_name` group.
