Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

Description Task 1: Include variables based on the detected OS distribution and family, prioritizing specific files and falling back to a main file. Uses `lookup('first_found')` to find the appropriate variable file.

Task 2: Include RedHat setup tasks.
Description Task 2: Include tasks specific to RedHat-based systems using `include_tasks` if the `ansible_facts.os_family` is 'RedHat'.

Task 3: Include Debian setup tasks.
Description Task 3: Include tasks specific to Debian-based systems using `include_tasks` if the `ansible_facts.os_family` is 'Debian'.

Task 4: Install Docker packages.

Task 5: Install Docker packages (with downgrade option).
Description Task 5: Install Docker packages using the `package` module, allowing downgrades.  Notify the `restart docker` handler and ignore errors during check mode. This task executes for Ansible versions 2.12 or greater and for RedHat/Debian systems.

Task 13: Get docker group info using getent.

Task 15: Include docker-users tasks.
