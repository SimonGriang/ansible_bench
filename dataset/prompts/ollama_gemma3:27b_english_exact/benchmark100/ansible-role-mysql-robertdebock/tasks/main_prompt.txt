Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the assert.yml task file, running it once on localhost.

Task 2: Install mysql
Description Task 2: Install the mysql packages defined in the `mysql_packages` variable and notify the `Set root password` and `Systemctl daemon-reexec` handlers.

Task 3: Configure mysql server
Description Task 3: Configure the mysql server by setting options in the `mysql_name`-server.cnf file based on the `mysql_configuration_options` list.

Task 4: Configure mysql client
Description Task 4: Configure the mysql client by setting the socket option in the `mysql_name`-client.cnf file.

Task 5: Initialize mysql
Description Task 5: Initialize mysql if the distribution is Alpine or Archlinux using the `mysql_initialize_command` command.

Task 6: Start and enable mysql
Description Task 6: Start and enable the mysql service defined in the `mysql_service` variable.

Task 7: Flush handlers
Description Task 7: Flush registered handlers to apply any pending changes.

Task 8: Place my.cnf
Description Task 8: Place a custom my.cnf file from the template `my.cnf.j2` to `/root/.my.cnf` with mode 0640.

Task 9: Create databases
Description Task 9: Create mysql databases defined in the `mysql_databases` list, setting their state, target, encoding, and collation. Uses `mysql_socket`, `root` user and `mysql_root_password` for login.

Task 10: List databases
Description Task 10: List existing databases using the `mysql_info` module, logging the output. Uses `mysql_socket`, `root` user and `mysql_root_password` for login.

Task 11: Import database
Description Task 11: Import databases defined in the `mysql_databases` list from a specified target, only if an initial import target is defined and the database does not already exist. Uses `mysql_socket`, `root` user and `mysql_root_password` for login.

Task 12: Create users
Description Task 12: Create mysql users defined in the `mysql_users` list, setting their password, privileges, and host. Uses `mysql_socket`, `root` user and `mysql_root_password` for login.

Task 13: Flush handlers again
Description Task 13: Flush registered handlers again to apply any pending changes.
