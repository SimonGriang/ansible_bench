Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the `assert.yml` task file, running it only once and delegating it to localhost.

Task 2: Enable redis module stream (RHEL 8)
Description Task 2: Enable the `redis` module stream using the `dnf` package manager, but only if the target system is a RedHat-based system with a major version of 8.

Task 3: Install redis
Description Task 3: Install the `redis` package using the system's package manager, ensuring it is present. The package name is taken from the variable `redis_packages`.

Task 4: Configure redis
Description Task 4: Configure redis by templating the `redis.conf-{{ ansible_distribution }}.j2` file to `{{ redis_configuration_directory }}/{{ redis_configuration_file }}` with the specified owner, group, and mode.  Notify the `Restart redis` handler after configuration.

Task 5: Start and enable redis
Description Task 5: Start and enable the `redis` service, ensuring it is running and starts automatically on boot. The service name is taken from the variable `redis_service`.
