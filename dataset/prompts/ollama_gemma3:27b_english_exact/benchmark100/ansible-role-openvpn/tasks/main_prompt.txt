Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the `assert.yml` tasks file to perform initial checks and validations. This task should run only once and delegate execution to localhost.

Task 2: Install openvpn packages
Description Task 2: Install the necessary openvpn packages using the package manager. The packages to install are defined by the variable `openvpn_packages` and should be ensured to be present.

Task 3: Setup openvpn server or client
Description Task 3: Include a task file to configure either an OpenVPN server or client, based on the value of the `openvpn_role` variable. This allows for conditional configuration based on the desired setup.

Task 4: Start and enable openvpn
Description Task 4: Start and enable the openvpn service using the service module. The service name is defined by the `openvpn_service` variable. The service should be in a started and enabled state.
