Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Install SSL packages
Description Task 1: Install the necessary SSL packages using the `httpd_ssl_packages` variable and ensure they are present on the system.

Task 2: Place SSL configuration
Description Task 2: Copy the `ssl.conf.j2` template to the `httpd_config_directory` as `ssl.conf` with permissions `0644`. Notify the `Test httpd configuration validity` and `Restart httpd` handlers after completion.

Task 3: Configure redirect from http to https
Description Task 3: Copy the `default_vhost.conf.j2` template to the `httpd_config_directory` as `default_vhost_conf` with permissions `0644`. Notify the `Test httpd configuration validity` and `Restart httpd` handlers after completion.
