Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the `assert.yml` tasks file to perform initial assertions. Run this task only once and delegate it to localhost.

Task 2: Install fail2ban
Description Task 2: Install the `fail2ban` package using the package manager. The package name is defined by the `fail2ban_packages` variable.

Task 3: Copy filters in filter.d
Description Task 3: Copy custom fail2ban filters from `fail2ban_filterd_path` to `/etc/fail2ban/filter.d/`. Set the owner to root, group to root, and permissions to 0640. Only execute if `fail2ban_filterd_path` is defined, and notify the `Restart fail2ban` handler.

Task 4: Configure fail2ban.local
Description Task 4: Configure options in the `/etc/fail2ban/fail2ban.local` file using the `ini_file` module. Loop through the list of configurations defined in `fail2ban_base_configuration` and `fail2ban_configuration`. Set the file mode to 0640 and notify the `Restart fail2ban` handler. Use the `option` field in the loop as the label.

Task 5: Configure jail.local
Description Task 5: Configure options in the `/etc/fail2ban/jail.local` file using the `ini_file` module. Loop through the list of configurations defined in `fail2ban_base_jail_configuration` and `fail2ban_jail_configuration`. Set the file mode to 0640 and notify the `Restart fail2ban` handler. Use the `option` field in the loop as the label.

Task 6: Stat auth log file
Description Task 6: Stat the `/var/log/auth.log` file and register the result in the `fail2ban_auth` variable.

Task 7: Touch auth log file
Description Task 7: Ensure the `/var/log/auth.log` file exists by touching it if it doesn't. Set the file mode to 0640. Only execute if the `fail2ban_auth.stat.exists` variable is defined and evaluates to false.

Task 8: Start and enable fail2ban
Description Task 8: Start and enable the `fail2ban` service using the `service` module. The service name is defined by the `fail2ban_service` variable.
