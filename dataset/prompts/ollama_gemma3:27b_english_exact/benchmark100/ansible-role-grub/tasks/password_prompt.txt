Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Check for EFI directory
Description Task 1: Use the `stat` module to check for the existence of the EFI directory `/sys/firmware/efi/efivars/` and register the output to the `grub_efi` variable.

Task 2: Remove existing grub.cfg on EFI systems
Description Task 2: Remove the file `/boot/grub2/grub.cfg` if the EFI directory exists, using the `file` module with `state: absent`. This is conditional on the `grub_efi.stat.exists` variable.

Task 3: Install user template for grub
Description Task 3: Deploy the template `01_users.j2` to `/etc/grub.d/01_users` with appropriate ownership (root:root) and permissions (0700) using the `template` module. Notify the `Update grub` handler after completion.

Task 4: Add password to grub configuration on EFI systems
Description Task 4: Add a line containing the grub password to `/etc/grub2-efi.cfg` using the `lineinfile` module. The line should only be added if the EFI directory exists (conditional on `grub_efi.stat.exists`). The `regexp` ensures the line is not duplicated, and `insertafter: EOF` appends it to the end of the file. Notify the `Update grub` handler after completion. The line format is `password_pbkdf2 {{ grub_user }} {{ grub_password }}`.

Task 5: Add password to grub configuration on MBR systems
Description Task 5: Add a line containing the grub password to `/etc/grub2.cfg` using the `lineinfile` module. The line should only be added if the EFI directory exists (conditional on `grub_efi.stat.exists`). The `regexp` ensures the line is not duplicated, and `insertafter: EOF` appends it to the end of the file. Notify the `Update grub` handler after completion. Task 6: Add --unrestricted flag to grub configuration
Description Task 6: Add the `--unrestricted` flag to specific grub configuration files defined in the `grub_password_unrestricted_files` list. This is done using the `replace` module, conditional on the `grub_password_unrestricted` variable. The `regexp` matches the `CLASS` attribute and replaces it with the original value plus `--unrestricted`. Notify the `Update grub` handler after completion.
