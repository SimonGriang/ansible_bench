Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Download RKE2 kubeconfig to localhost
Description Task 1: Download the RKE2 kubeconfig file from the remote server to the localhost, using the `fetch` module. The source file is `/etc/rancher/rke2/rke2.yaml` and the destination is defined by the variables `rke2_download_kubeconf_path` and `rke2_download_kubeconf_file_name`. The `flat: yes` option ensures that the directory structure is not replicated. This task is conditional and only runs if `rke2_download_kubeconf` is true and the current host is the first server in the `rke2_servers_group_name` group.

Task 2: Replace loopback IP by master server IP
Description Task 2: Replace the loopback IP address (127.0.0.1 or [::1]) in the downloaded kubeconfig file with the IP address of the master server. This is done using the `replace` module. The file to modify is defined by `rke2_download_kubeconf_path` and `rke2_download_kubeconf_file_name`. The `regexp` matches the loopback IPs, and the `replace` value is determined by the variable `rke2_api_ip` if it's defined; otherwise, it uses the `ansible_host` variable of the first server in the `rke2_servers_group_name` group. The task is delegated to localhost, does not require privilege escalation (`become: false`), and is skipped in check mode (`ansible_check_mode`). The task is also conditional and only runs if `rke2_download_kubeconf` is true and the current host is the first server in the `rke2_servers_group_name` group.
