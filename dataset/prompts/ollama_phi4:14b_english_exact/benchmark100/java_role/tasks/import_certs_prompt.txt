Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Check if Java certificates exist on the system.  
Description Task 1: This task checks the existence of each certificate in the list of Java certificates using the `stat` module and registers the results for further processing.

Task 2: Fail the playbook if any Java certificate is missing.  
Description Task 2: This task ensures that all necessary Java certificates exist by failing the playbook with an appropriate error message if any certificate is not found, using the results from the previous check.

Task 3: Set keystore directory variables for Java versions less than 11.  
Description Task 3: This task sets the keystore directory path for Java versions less than 11 using the `set_fact` module, ensuring the correct directory is used based on the Java version.

Task 4: Set keystore directory variables for Java versions 11 and above.  
Description Task 4: This task sets the keystore directory path for Java versions 11 and above using the `set_fact` module, ensuring the correct directory is used based on the Java version.

Task 5: Import SSL certificates into the Java keystore.  
Description Task 5: This task imports each SSL certificate into the Java keystore using the `java_cert` module, ensuring that the certificates are present and the keystore is created if necessary.
