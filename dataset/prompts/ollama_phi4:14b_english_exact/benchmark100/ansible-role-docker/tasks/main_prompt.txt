Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

Task 3: Include Debian-specific setup tasks if the OS family is Debian.  
Description Task 3: Use `include_tasks` to run setup tasks for Debian systems by including the `setup-Debian.yml` file when the OS family matches 'Debian'.

Notify the `restart docker` handler and ignore errors if in check mode. This task should run when the Ansible version is less than 2.12 or the OS family is neither RedHat nor Debian.
