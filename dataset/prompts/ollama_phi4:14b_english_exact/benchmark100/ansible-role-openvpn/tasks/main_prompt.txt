Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Import the assert.yml file to perform assertions or validations. This task is executed once and delegated to the localhost.

Task 2: Install openvpn packages  
Description Task 2: Install the packages required for OpenVPN using the variable `openvpn_packages`. Ensure these packages are present on the system.

Task 3: Setup openvpn server or client  
Description Task 3: Include tasks from a file named based on the `openvpn_role` variable to configure OpenVPN as either a server or client.

Task 4: Start and enable openvpn  
Description Task 4: Start and enable the OpenVPN service using the `openvpn_service` variable to ensure the service is running and enabled on boot.
