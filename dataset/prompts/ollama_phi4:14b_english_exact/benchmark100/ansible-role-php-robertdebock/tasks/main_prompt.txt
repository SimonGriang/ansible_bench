Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import an external tasks file for assertions.  
Description Task 1: Import the assert.yml tasks file to be executed once and delegated to localhost. This is used for specific assertions or checks.

Task 2: Install PHP.  
Description Task 2: Use the package module to install PHP using a variable, `php_packages`, which contains the necessary package names.

Task 3: Find the used php.ini file.  
Description Task 3: Execute a shell command to locate the php.ini file using `php_ini_command`. Register the output in `php_found_ini_location` and ensure it does not mark the task as changed. Execute this only if `php_ini_location` is not predefined.

Task 4: Configure PHP.  
Description Task 4: Use the template module to deploy a configuration file, `php.ini.j2`, to the determined php.ini location. Ensure the file has the appropriate permissions (0644) and trigger a handler to restart the httpd service if changes are made.
