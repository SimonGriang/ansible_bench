Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Import tasks from assert.yml to be run once on the localhost.

Task 2: Install cron  
Description Task 2: Ensure the cron packages specified in the `cron_packages` variable are installed.

Task 3: Configure shell  
Description Task 3: Set the SHELL environment variable in the cron configuration file using the `cron_shell` variable. Notify the handler to restart cron if changes are made.

Task 4: Configure path  
Description Task 4: Set the PATH environment variable in the cron configuration file using the `cron_path` variable. Notify the handler to restart cron if changes are made.

Task 5: Configure mailto

Task 6: Start and enable cron

Task 7: Schedule requested cron jobs
