Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Create the RKE2 configuration directory.  
Description Task 1: Set up a directory at `/etc/rancher/rke2` with root ownership and 0755 permissions to store RKE2 configurations.

Task 2: Set server-specific node taints.  
Description Task 2: Assign node taints specifically for RKE2 server nodes using the `rke2_server_node_taints` variable, conditional on `rke2_type` being 'server'.

Task 3: Template the RKE2 configuration file.  
Description Task 3: Use a template for the RKE2 configuration file, copying it from `{{ rke2_config }}` to `/etc/rancher/rke2/config.yaml` with root ownership and 0600 permissions. Trigger the "Config file changed" handler upon completion.

Task 4: Template the kubelet configuration file.  
Description Task 4: Conditionally create a kubelet configuration file from a template `templates/kubelet-config.yaml.j2` to `/etc/rancher/rke2/kubelet-config.yaml` if `rke2_kubelet_config` is not empty, with root ownership and 0600 permissions, triggering the "Config file changed" handler.

Task 5: Configure Containerd registry settings.  
Description Task 5: Conditionally copy a Containerd registry configuration file from `{{ rke2_custom_registry_path }}` to `/etc/rancher/rke2/registries.yaml` if either `rke2_custom_registry_mirrors` or `rke2_custom_registry_configs` are not empty, with root ownership and 0600 permissions, triggering the "Config file changed" handler.

Task 6: Determine if an etcd restore from a file is necessary.  
Description Task 6: Set a fact `do_etcd_restore` to true if an etcd snapshot file is specified and the `rke2-server` service is not running or is disabled.

Task 7: Determine if an etcd restore from S3 is necessary.  
Description Task 7: Set a fact `do_etcd_restore_from_s3` to true if an etcd snapshot file is specified along with defined S3 credentials and bucket information.

Task 8: Restore etcd from a snapshot file.  
Description Task 8: If `do_etcd_restore` is true, create the snapshot directory, copy the snapshot file, and execute the `rke2 server` command to restore etcd from the snapshot, registering the task output and marking the task as changed if the return code is non-zero.

Task 9: Restore etcd from an S3 snapshot.  
Description Task 9: If `do_etcd_restore_from_s3` is true, execute the `rke2 server` command with S3 options to restore etcd from an S3 snapshot, registering the task output and marking the task as changed if the return code is non-zero.

Task 10: Start the RKE2 server service.  
Description Task 10: Start and enable the `rke2-server.service`, setting the `RKE2_TOKEN` environment variable, and notify "Service (re)started" upon completion.

Task 11: Mask the RKE2 agent service.  
Description Task 11: Disable and mask the `rke2-agent.service` to prevent it from starting.

Task 12: Wait for the first server to be ready without CNI.  
Description Task 12: Check the server readiness status for specific conditions using `kubectl`, retrying 100 times with a 15-second delay, only if `rke2_cni` is set to 'none'.

Task 13: Wait for the first server to be ready with CNI.  
Description Task 13: Check if the server is marked as "Ready" using `kubectl`, retrying 40 times with a 15-second delay, only if `rke2_cni` is not 'none'.

Task 14: Clean up old nodes and secrets if restoring etcd.  
Description Task 14: If either `do_etcd_restore` or `do_etcd_restore_from_s3` is true, retrieve registered node names, identify nodes no longer present, and delete associated secrets and nodes.

Task 15: Set the active server variable.  
Description Task 15: Set a fact `active_server` to the current inventory hostname by delegating to each host in the `rke2_cluster_group_name` group.
