Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Download the RKE2 kubeconfig file to a specified path on localhost.  
Description Task 1: This task uses the `ansible.builtin.fetch` module to copy the RKE2 kubeconfig file from the source path `/etc/rancher/rke2/rke2.yaml` to the destination path specified by the variables `rke2_download_kubeconf_path` and `rke2_download_kubeconf_file_name` on localhost. The task ensures the file is downloaded only if the variable `rke2_download_kubeconf` is true and the current host is the first in the `rke2_servers_group_name` group.

Task 2: Replace loopback IP addresses in the downloaded kubeconfig file with the master server IP.  
Description Task 2: This task uses the `ansible.builtin.replace` module to substitute loopback IP addresses (`127.0.0.1` and `[::1]`) in the downloaded kubeconfig file with the master server IP address. The IP address is determined by the variable `rke2_api_ip` or, if not set, defaults to the host IP of the first server in the `rke2_servers_group_name` group. The file permissions are set to `0600`. This task is executed on localhost and is skipped in check mode. It only runs if the variable `rke2_download_kubeconf` is true and the current host is the first in the `rke2_servers_group_name` group.
