Description Task 1: Execute a shell command to retrieve and display the state of K8s nodes including their labels using the kubectl tool. Use the rke2_data_path variable for the path to the kubectl binary and /etc/rancher/rke2/rke2.yaml for the kubeconfig file. Set the shell executable to /bin/bash, and configure the task to not mark the host as changed. Implement retry logic with a maximum of 5 attempts and register the output to a variable named nodes_summary.

Task 2: Display the state of K8s nodes.
Description Task 2: Output the retrieved node information from the nodes_summary variable to the Ansible debug console to display the state of the K8s nodes.
