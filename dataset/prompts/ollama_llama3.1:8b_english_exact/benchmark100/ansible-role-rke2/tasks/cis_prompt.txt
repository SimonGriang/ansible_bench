Below you will receive task descriptions from which you should generate an Ansible Playbook.

Task 1: Create a system group named etcd and ensure it exists.
Description: This task will create a system group named etcd, which is a necessary step for configuring the etcd service.

Task 2: Create a system user named etcd, assign it to the etcd group, and set its shell to /bin/nologin.
Description: This task will create a system user named etcd, assign it to the etcd group, and set its shell to /bin/nologin, ensuring the user is locked and cannot login.

Task 3: Copy the systemctl config file for kernel hardening to the /etc/sysctl.d/ directory, using a conditional source file based on the writeability of the /usr/local/share directory and the result of a command.
Description: This task will copy the systemctl config file for kernel hardening to the /etc/sysctl.d/ directory, using a conditional source file based on the writeability of the /usr/local/share directory and the result of a command, and notify the Restart systemd-sysctl handler.

Task 4: Flush the handlers to run pending tasks.
Description: This task will flush the handlers to run any pending tasks, ensuring that any notified tasks are executed.
