Below you will receive task descriptions from which you should generate an Ansible Playbook.

The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

Task 1: Download RKE2 kubeconfig from master server to localhost.
Description Task 1: Download the RKE2 kubeconfig file from the master server to the local machine, using the specified path and file name. The file is downloaded using the `fetch` module, and the `flat` parameter is set to `yes` to flatten the file structure.

Task 2: Replace loopback IP with master server IP in kubeconfig file.
Description Task 2: Replace the loopback IP address (`127.0.0.1` or `[::1]`) in the kubeconfig file with the master server's IP address. The `replace` module is used with a regular expression to find and replace the loopback IP address with the master server's IP address. The `mode` parameter is set to `0600` to set the file permissions. The `delegate_to` parameter is set to `localhost` to run the task on the local machine, and `become` is set to `false` to prevent privilege escalation.
