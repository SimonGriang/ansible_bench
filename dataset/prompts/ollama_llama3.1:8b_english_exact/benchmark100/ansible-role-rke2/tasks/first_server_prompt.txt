Below you will receive task descriptions from which you should generate an Ansible Playbook.

The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).

Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

Task 1: Create the RKE2 config directory
Description Task 1: Create the configuration directory for RKE2 at /etc/rancher/rke2 with root owner and group, mode 0755.

Task 2: Set server taints
Description Task 2: Set combined node taints to the value of rke2_server_node_taints when the server type is 'server'.

Task 3: Copy RKE2 config
Description Task 3: Copy the RKE2 config file from the template "{{ rke2_config }}" to /etc/rancher/rke2/config.yaml with root owner and group, mode 0600, and notify the "Config file changed" handler.

Task 4: Copy kubelet config
Description Task 4: Copy the kubelet config file from the template "templates/kubelet-config.yaml.j2" to /etc/rancher/rke2/kubelet-config.yaml with root owner and group, mode 0600, and notify the "Config file changed" handler when the length of rke2_kubelet_config is greater than 0.

Task 5: Copy Containerd Registry Configuration file
Description Task 5: Copy the Containerd Registry Configuration file from the path "{{ rke2_custom_registry_path }}" to /etc/rancher/rke2/registries.yaml with root owner and group, mode 0600, and notify the "Config file changed" handler when the length of rke2_custom_registry_mirrors or rke2_custom_registry_configs is greater than 0.

Task 6: Register etcd restore from file
Description Task 6: Set the do_etcd_restore fact to true when the length of rke2_etcd_snapshot_file is greater than 0, and the rke2-server.service is not defined or its status is disabled.

Task 7: Register etcd restore from s3
Description Task 7: Set the do_etcd_restore_from_s3 fact to true when the length of rke2_etcd_snapshot_file is greater than 0, and the rke2_etcd_snapshot_s3_options are defined, including access_key, secret_key, bucket, and snapshot_name.

Task 8: Restore etcd from file
Description Task 8: Restore etcd from a snapshot file when the do_etcd_restore fact is defined, by creating the RKE2 etcd snapshot directory, copying the etcd snapshot file, and restoring etcd from the snapshot using the rke2 server command.

Task 9: Restore etcd from s3
Description Task 9: Restore etcd from a snapshot stored in s3 when the do_etcd_restore_from_s3 fact is defined, by restoring etcd from the s3 snapshot using the rke2 server command.

Task 10: Start RKE2 service on the first server
Description Task 10: Start the rke2-server.service on the first server with the RKE2_TOKEN environment variable set to the value of rke2_token, and notify the "Service (re)started" handler.

Task 11: Mask RKE2 agent service on the first server
Description Task 11: Mask the rke2-agent.service on the first server.

Task 12: Wait for the first server be ready - no CNI
Description Task 12: Wait for the first server to be ready, without CNI, by running the kubectl command to get the node status, until the node is ready and there is no CNI plugin initialized.

Task 13: Wait for the first server be ready - with CNI
Description Task 13: Wait for the first server to be ready, with CNI, by running the kubectl command to get the nodes, until the node is ready.

Task 14: Restore etcd
Description Task 14: Restore etcd by removing old secrets and nodes, and then creating new nodes.

Task 15: Set an Active Server variable
Description Task 15: Set the active_server fact to the value of the inventory_hostname, and delegate the task to each server in the rke2_cluster_group_name group.
