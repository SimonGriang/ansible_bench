Below you will receive task descriptions from which you should generate an Ansible Playbook.

Task 1: Restore etcd node names.
Description Task 1: Run a Kubernetes command to get the names of all nodes in the cluster. The output should be stored in the `node_names` variable.

Task 2: Remove old nodes from the cluster.
Description Task 2: For each node that is present in the `node_names` variable but not in the `groups[rke2_cluster_group_name]` group, delete the node using a Kubernetes command. Ignore any errors that may occur.
