Below you will receive task descriptions from which you should generate an Ansible Playbook.

The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).

Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

Task 1: Get the path to the efi variables directory.
Description Task 1: The task will use the ansible.builtin.stat module to check if the /sys/firmware/efi/efivars/ directory exists. The result will be stored in the grub_efi variable.

Task 2: Remove the grub.cfg file on EFI systems.
Description Task 2: If the efi variables directory exists, the task will use the ansible.builtin.file module to delete the /boot/grub2/grub.cfg file.

Task 3: Install a user template for grub.
Description Task 3: The task will use the ansible.builtin.template module to copy the 01_users.j2 template to the /etc/grub.d/01_users file, with the correct permissions and ownership. This task will also trigger the Update grub handler.

Task 4: Add password to the grub configuration on EFI systems.
Description Task 4: If the efi variables directory exists, the task will use the ansible.builtin.lineinfile module to add a password line to the /etc/grub2-efi.cfg file. The line will be inserted after the EOF marker. This task will also trigger the Update grub handler.

Task 5: Add password to the grub configuration on MBR systems.
Description Task 5: If the efi variables directory exists, the task will use the ansible.builtin.lineinfile module to add a password line to the /etc/grub2.cfg file. The line will be inserted after the EOF marker. This task will also trigger the Update grub handler.

Task 6: Modify the grub configuration to allow unrestricted access.
Description Task 6: If the grub_password_unrestricted variable is True, the task will use the ansible.builtin.replace module to add the --unrestricted option to the grub configuration files listed in the grub_password_unrestricted_files variable. This task will also trigger the Update grub handler.
