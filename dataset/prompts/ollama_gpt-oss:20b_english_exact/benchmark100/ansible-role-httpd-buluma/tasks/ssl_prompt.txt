Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: ssl | Install ssl packages  
Description Task 1: Install the SSL packages required for the HTTP server, using the variable `httpd_ssl_packages` to specify the list of packages to be installed.

Task 2: ssl | Place configuration  
Description Task 2: Deploy the `ssl.conf` configuration file by rendering the template `ssl.conf.j2` to the destination `${httpd_config_directory}/ssl.conf` with file mode `0644`. After placement, notify the handlers `Test httpd configuration validity` and `Restart httpd`.

Task 3: ssl | Configure redirect from http to https  
Description Task 3: Deploy the default virtual host configuration that redirects HTTP to HTTPS by rendering the template `default_vhost.conf.j2` to the destination `${httpd_config_directory}/${default_vhost_conf}` with file mode `0644`. After placement, notify the handlers `Test httpd configuration validity` and `Restart httpd`.
