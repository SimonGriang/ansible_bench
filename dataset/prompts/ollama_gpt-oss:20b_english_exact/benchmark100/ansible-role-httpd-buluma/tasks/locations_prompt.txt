Task 2: locations | Configure locations  
Description Task 2: Generate Apache location configuration files from the template `location.conf.j2`. The task should iterate over the list `httpd_locations`, creating a file named `{{ item.name }}.conf` in the directory specified by the variable `httpd_config_directory`. Set the file mode to `0644`. Use `loop_control` to label each iteration with the location name. After the template is applied, notify the handlers `Test httpd configuration validity` and `Restart httpd`.
