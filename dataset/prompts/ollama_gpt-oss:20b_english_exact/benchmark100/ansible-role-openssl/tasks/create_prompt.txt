Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: create | Create ssl key  
Description Task 1: Use the `community.crypto.openssl_privatekey` module to generate a private key file named `{{ item.name }}.key` in the directory `{{ openssl_key_directory }}`. Set the file mode to `640`, owner to `{{ openssl_file_owner }}`, and group to `{{ openssl_file_group }}`.  

Task 2: create | Create ssl csr  
Description Task 2: Use the `community.crypto.openssl_csr` module to create a certificate signing request (CSR) named `{{ item.name }}.csr` in `{{ openssl_csr_directory }}`. Reference the private key located at `{{ openssl_key_directory }}/{{ item.name }}.key`, set the `common_name` to `{{ item.common_name }}`, and set file mode to `644`, owner to `{{ openssl_file_owner }}`, and group to `{{ openssl_file_group }}`.  

Task 3: create | Create ssl certificates  
Description Task 3: Use the `community.crypto.x509_certificate` module to create a self‑signed certificate named `{{ item.name }}.crt` in `{{ openssl_crt_directory }}`. Use the private key at `{{ openssl_key_directory }}/{{ item.name }}.key` and the CSR at `{{ openssl_csr_directory }}/{{ item.name }}.csr`. Set `provider` to `selfsigned`, file mode to `644`, owner to `{{ openssl_file_owner }}`, and group to `{{ openssl_file_group }}`.  

Task 4: create | Create PKCS#12 file  
Description Task 4: Use the `community.crypto.openssl_pkcs12` module to export a PKCS#12 file named `{{ item.name }}.p12` in `{{ openssl_key_directory }}`. Include the private key and certificate, set `friendly_name` to `{{ item.name }}`, set `state` to `present`, file mode to `640`, owner to `{{ openssl_file_owner }}`, and group to `{{ openssl_file_group }}`.  

Task 5: create | Read private key  
Description Task 5: Use the `ansible.builtin.slurp` module to read the private key file `{{ openssl_key_directory }}/{{ item.name }}.key` into the variable `openssl_private_key`.  

Task 6: create | Read certificate  
Description Task 6: Use the `ansible.builtin.slurp` module to read the certificate file `{{ openssl_crt_directory }}/{{ item.name }}.crt` into the variable `openssl_certifcate`.  

Task 7: create | Create combined private_key and certificate file  
Description Task 7: Use the `ansible.builtin.copy` module to create a combined file `{{ openssl_key_directory }}/{{ item.name }}.keycrt`. The file content is constructed by decoding `openssl_private_key.content` and `openssl_certifcate.content`, trimming whitespace, and concatenating them with a newline. Set file mode to `640`, owner to `{{ openssl_file_owner }}`, and group to `{{ openssl_file_group }}`.
