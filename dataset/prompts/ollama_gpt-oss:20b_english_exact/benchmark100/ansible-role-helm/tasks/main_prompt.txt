Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Check if Helm binary exists.  
Description Task 1: Use the `stat` module to check whether the path stored in the variable `helm_bin_path` exists. Register the result as `helm_check`.  

Task 2: Check Helm version.  
Description Task 2: Run the command `{{ helm_bin_path }} version` using the `command` module, set `failed_when: false` and `changed_when: false`, and register the output as `helm_existing_version`.  

Task 3: Download helm.  
Description Task 3: Use the `unarchive` module to download the Helm tarball from `{{ helm_repo_path }}/helm-{{ helm_version }}-{{ helm_platform }}-{{ helm_arch }}.tar.gz` to `/tmp`. Set `remote_src: true`, `mode: 0755`, and register the task as `helm_download`. Only run this task when the Helm binary does not exist (`not helm_check.stat.exists`) or the desired `helm_version` is not found in `helm_existing_version.stdout`.  

Task 4: Copy helm binary into place.  
Description Task 4: Copy the extracted Helm binary from `/tmp/{{ helm_platform }}-{{ helm_arch }}/helm` to the destination `{{ helm_bin_path }}` using the `copy` module with `mode: 0755` and `remote_src: true`. Run this task with privilege escalation (`become: true`) only when the download task changed (`helm_download is changed`).
