Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Download RKE2 kubeconfig to localhost  
Description Task 1: Use the `ansible.builtin.fetch` module to download the RKE2 kubeconfig file located at `/etc/rancher/rke2/rke2.yaml` from the first host in the group named by the variable `rke2_servers_group_name`. The file should be saved locally to the path constructed from the variables `rke2_download_kubeconf_path` and `rke2_download_kubeconf_file_name`, with the `flat: yes` option. This task must run only when the boolean variable `rke2_download_kubeconf` is true and the current host is the first host in the `rke2_servers_group_name` group.

Task 2: Replace loopback IP by master server IP  
Description Task 2: Use the `ansible.builtin.replace` module to modify the downloaded kubeconfig file. The module should target the file located at the path built from `rke2_download_kubeconf_path` and `rke2_download_kubeconf_file_name`. It must replace any occurrence of `127.0.0.1` or `[::1]` (regex `127\.0\.0\.1|\[::1\]`) with the IP address defined by the variable `rke2_api_ip`; if `rke2_api_ip` is not set, use the `ansible_host` of the first host in the `rke2_servers_group_name` group, wrapped with `ansible.utils.ipwrap`. The file permissions should be set to `0600`. This task should delegate to `localhost` and not use privilege escalation (`become: false`). It should execute only when `ansible_check_mode` is false, `rke2_download_kubeconf` is true, and the current host is the first host in the `rke2_servers_group_name` group.
