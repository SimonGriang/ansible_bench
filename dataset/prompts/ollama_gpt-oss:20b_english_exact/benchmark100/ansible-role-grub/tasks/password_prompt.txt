Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Get efi path  
Description Task 1: Use the stat module to check whether the EFI firmware directory `/sys/firmware/efi/efivars/` exists, and register the result as the variable `grub_efi`.

Task 2: Remove unwanted grub.cfg on EFI systems  
Description Task 2: Remove the file `/boot/grub2/grub.cfg` on systems that have EFI firmware detected (`grub_efi.stat.exists` is true).

Task 3: Install user template  
Description Task 3: Deploy the Jinja2 template `01_users.j2` to `/etc/grub.d/01_users` with owner `root`, group `root`, and mode `0700`. Notify the handler `Update grub` after the template is installed.

Task 4: EFI | add password  
Description Task 4: Add a line to `/etc/grub2-efi.cfg` that sets the GRUB password for the user defined by `{{ grub_user }}` using the password hash `{{ grub_password }}`. The line should match the regexp `^password_pbkdf2 {{ grub_user }} `, be inserted after the end of the file, and be added only if EFI firmware is present (`grub_efi.stat.exists`). Notify `Update grub`.

Task 5: MBR | add password  
Description Task 5: Add a line to `/etc/grub2.cfg` that sets the GRUB password for the user defined by `{{ grub_user }}` using the password hash `{{ grub_password }}`. The line should match the regexp `^password_pbkdf2 {{ grub_user }} `, be inserted after the end of the file, and be added only if EFI firmware is present (`grub_efi.stat.exists`). Notify `Update grub`.

Task 6: Add --unrestricted  
Description Task 6: For each file listed in the variable `{{ grub_password_unrestricted_files }}`, replace the `CLASS` attribute to include the `--unrestricted` flag. The replacement should match the regexp `^CLASS="(((?!--unrestricted).)*)"$` and replace it with `CLASS="\1 --unrestricted"`. This task should run only if `{{ grub_password_unrestricted }}` is true, and notify `Update grub`.
