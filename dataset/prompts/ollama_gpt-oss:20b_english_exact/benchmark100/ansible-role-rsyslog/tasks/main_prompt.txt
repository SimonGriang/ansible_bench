Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Import tasks from the file `assert.yml` using `ansible.builtin.import_tasks`. This task should run only once (`run_once: true`) and delegate to `localhost`.  

Task 2: Uninstall conflicting systemd-logger  
Description Task 2: Remove the package `systemd-logger` from the system using `ansible.builtin.package` with `state: absent`.  

Task 3: Install rsyslog  
Description Task 3: Install the rsyslog packages specified in the variable `rsyslog_packages` with the state defined by `rsyslog_package_state` using `ansible.builtin.package`.  

Task 4: Install additional rsyslog packages  
Description Task 4: Loop over the list `rsyslog_features` and install each package named `rsyslog-{{ item }}` with the state from `rsyslog_package_state` using `ansible.builtin.package`.  

Task 5: Configuring default rsyslog  
Description Task 5: Deploy the default rsyslog configuration file by templating `{{ rsyslog_config_file_format }}_rsyslog.conf.j2` to the destination `{{ rsyslog_dest_conf_file }}` with mode `0644`. This task should only run when `rsyslog_deploy_default_config` is true and should notify the handler `Restart rsyslog`.  

Task 6: Make configuration directory  
Description Task 6: Ensure the directory `/etc/rsyslog.d/` exists with state `directory` and mode `0755` using `ansible.builtin.file`.  

Task 7: Configuring rsyslog forward rule  
Description Task 7: Deploy the forward rule configuration by templating `forward_rule.conf.j2` to `/etc/rsyslog.d/{{ rsyslog_forward_rule_name }}.conf` with mode `0644`. This task should only run when `not rsyslog_deploy_default_config` and should notify `Restart rsyslog`.  

Task 8: Configuring additional config files  
Description Task 8: Copy additional rsyslog configuration files defined in the dictionary `rsyslog_rsyslog_d_files` to `/etc/rsyslog.d/{{ item.key }}.conf`. The content comes from `item.value.content` (default empty string), validation uses `rsyslogd -N1 -f %s` if `item.value.validate` is true, otherwise `true %s`. Set owner and group to `root`, mode `0440`, and notify `Restart rsyslog` when the file state is `present`.  

Task 9: Start and enable rsyslog  
Description Task 9: Ensure the rsyslog service specified by the variable `rsyslog_service` is started and enabled using `ansible.builtin.service`.
