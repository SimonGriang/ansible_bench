Task 1: Check current docker-compose version.  
Description Task 1: Execute the docker-compose binary located at `{{ docker_compose_path }}` with the `--version` flag to capture its current version string. Description Task 2: Remove the file at `{{ docker_compose_path }}` only when a current version is detected and the installed version does not match the desired `{{ docker_compose_version }}` (after stripping any leading `v`). This ensures an old or mismatched binary is deleted before a new one is installed.  

Task 3: Install Docker Compose (if configured).  
Description Task 3: Use `get_url` to download the Docker Compose binary from `{{ docker_compose_url }}` to `{{ docker_compose_path }}` with mode `0755`.
