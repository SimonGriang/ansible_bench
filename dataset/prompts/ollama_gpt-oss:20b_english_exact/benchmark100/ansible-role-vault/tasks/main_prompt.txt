Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Import the assert.yml tasks file, run it only once, and delegate the execution to localhost.  

Task 2: Install prerequisites  
Description Task 2: Use the package module to install all packages listed in the variable `vault_prerequisites`.  

Task 3: Include installation method specific tasks  
Description Task 3: Include the tasks file named after the value of the variable `vault_installation_method` with a `.yml` extension (e.g., `{{ vault_installation_method }}.yml`).  

Task 4: Add Vault environment variables  
Description Task 4: Add each environment variable defined in the list `vault_environment_settings` to the file `/etc/vault.d/vault.env`, creating the file if it does not exist, using a regular expression to match existing lines, setting the line to `{{ item.name }}={{ item.value }}`, setting file mode to `0644`, looping over `vault_environment_settings`, and notifying the handler `Restart vault`.  

Task 5: Include hardening tasks  
Description Task 5: Include the tasks file `hardening.yml`.  

Task 6: Start and enable vault  
Description Task 6: Start and enable the `vault` service only when the variable `vault_type` equals `"oss"`.  

Task 7: Enable vault  
Description Task 7: Enable the `vault` service only when the variable `vault_type` does not equal `"oss"`.
