Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: create | Create ssl key  
Description Task 1: Generate a private key for each SSL certificate item using the `community.crypto.openssl_privatekey` module. The key is written to `{{ openssl_key_directory }}/{{ item.name }}.key`, set to mode `600`, and owned by `{{ openssl_file_owner }}:{{ openssl_file_group }}`.  

Task 2: create | Create ssl csr  
Description Task 2: Create a certificate signing request (CSR) for each SSL certificate item with the `community.crypto.openssl_csr` module. The CSR uses the private key from `{{ openssl_key_directory }}/{{ item.name }}.key`, sets the `common_name` to `{{ item.common_name }}`, and writes the CSR to `{{ openssl_csr_directory }}/{{ item.name }}.csr` with mode `640` and ownership `{{ openssl_file_owner }}:{{ openssl_file_group }}`.  

Task 3: create | Create ssl certificates  
Description Task 3: Generate a self‑signed X.509 certificate for each item using the `community.crypto.x509_certificate` module. The certificate is created from the CSR and private key, stored at `{{ openssl_crt_directory }}/{{ item.name }}.crt`, set to mode `640`, owned by `{{ openssl_file_owner }}:{{ openssl_file_group }}`, and the provider is `selfsigned`.  

Task 4: create | Create PKCS#12 file  
Description Task 4: Export a PKCS#12 bundle for each certificate item with the `community.crypto.openssl_pkcs12` module. The bundle is named `{{ item.name }}.p12`, stored in `{{ openssl_key_directory }}`, uses `friendly_name: {{ item.name }}`, includes the private key and certificate, is present, set to mode `600`, and owned by `{{ openssl_file_owner }}:{{ openssl_file_group }}`.  

Task 5: create | Read private key  
Description Task 5: Read the private key file for each item into the variable `openssl_private_key` using `ansible.builtin.slurp`. The source file is `{{ openssl_key_directory }}/{{ item.name }}.key`.  

Task 6: create | Read certificate  
Description Task 6: Read the certificate file for each item into the variable `openssl_certifcate` using `ansible.builtin.slurp`. The source file is `{{ openssl_crt_directory }}/{{ item.name }}.crt`.  

Task 7: create | Create combined private_key and certificate file  
Description Task 7: Create a combined file containing the decoded private key and certificate for each item using `ansible.builtin.copy`. The destination is `{{ openssl_key_directory }}/{{ item.name }}.keycrt`, mode `600`, owned by `{{ openssl_file_owner }}:{{ openssl_file_group }}`, and the content concatenates the base64‑decoded `openssl_private_key.content` and `openssl_certifcate.content`.
