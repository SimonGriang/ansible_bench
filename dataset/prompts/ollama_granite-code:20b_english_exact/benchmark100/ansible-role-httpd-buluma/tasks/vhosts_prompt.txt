The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).

Task 1: Create docroot directory for each virtual host
Description Task 1: Use the 'file' module to create the directory specified by the 'documentroot' variable for each virtual host defined in the 'httpd_vhosts' variable. Set the mode to '0755'. Only create the directory if the 'create_docroot' variable is not defined or if it is set to true for each virtual host. Use a loop and loop_control to iterate over the 'httpd_vhosts' variable and set a label for each task.

Task 2: Configure virtual host settings
Description Task 2: Use the 'template' module to generate the configuration file for each virtual host based on the template specified by the 'vhost_conf_template' variable. Set the destination to the 'httpd_vhosts_directory' with the virtual host name appended to the filename. Set the mode to '0644'. Use a loop and loop_control to iterate over the 'httpd_vhosts' variable and set a label for each task. Trigger the 'Test httpd configuration validity' handler and the 'Restart httpd' handler when the task is changed.
