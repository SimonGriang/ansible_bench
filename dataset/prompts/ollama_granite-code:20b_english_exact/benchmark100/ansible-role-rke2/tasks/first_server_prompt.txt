Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.

Task 2: Set server taints
Description Task 2: Set server taints based on the value of rke2_server_node_taints

Task 3: Copy rke2 config
Description Task 3: Copy the rke2 config file from the specified source to /etc/rancher/rke2/config.yaml and set file permissions to 0600

Task 4: Copy kubelet config
Description Task 4: Copy the kubelet config file from the specified source to /etc/rancher/rke2/kubelet-config.yaml and set file permissions to 0600, if the rke2_kubelet_config variable is not empty

Task 5: Copy Containerd Registry Configuration file
Description Task 5: Copy the Containerd Registry Configuration file from the specified source to /etc/rancher/rke2/registries.yaml and set file permissions to 0600, if the rke2_custom_registry_mirrors or rke2_custom_registry_configs variables are not empty

Task 6: Register if we need to do a etcd restore from file
Description Task 6: Register whether etcd needs to be restored from a file based on the value of rke2_etcd_snapshot_file and the status of the rke2-server.service

Task 7: Register if we need to do a etcd restore from s3
Description Task 7: Register whether etcd needs to be restored from s3 based on the presence of rke2_etcd_snapshot_s3_options.access_key, rke2_etcd_snapshot_s3_options.secret_key, rke2_etcd_snapshot_s3_options.bucket, and rke2_etcd_snapshot_s3_options.snapshot_name

Task 8: Restore etcd from file
Description Task 8: Restore etcd from a file if do_etcd_restore is defined, by creating the RKE2 etcd snapshot directory, copying the etcd snapshot file, and restoring etcd from the snapshot

Task 9: Restore etcd from s3
Description Task 9: Restore etcd from s3 if do_etcd_restore_from_s3 is defined, by executing the rke2 server command with appropriate options for s3 restore

Task 10: Start RKE2 service on the first server
Description Task 10: Start the RKE2 service on the first server and enable it to start at boot time

Task 11: Mask RKE2 agent service on the first server
Description Task 11: Mask the RKE2 agent service on the first server to prevent it from starting

Task 12: Wait for the first server be ready - no CNI
Description Task 12: Wait for the first server to be ready based on specific conditions related to memory, disk, and PID availability, with or without CNI

Task 13: Wait for the first server be ready - with CNI
Description Task 13: Wait for the first server to be ready based on the presence of the "Ready" status, with or without CNI

Task 14: Restore etcd
Description Task 14: Restore etcd if do_etcd_restore or do_etcd_restore_from_s3 is defined, by removing old <node>.node-password.rke2 secrets and old nodes and then executing the rke2 server command to remove old nodes and secrets

Task 15: Set an Active Server variable
Description Task 15: Set the active_server variable to the current inventory_hostname and delegate the task to other hosts in the rke2_cluster_group_name group, ensuring that the delegate_facts option is set to true.
