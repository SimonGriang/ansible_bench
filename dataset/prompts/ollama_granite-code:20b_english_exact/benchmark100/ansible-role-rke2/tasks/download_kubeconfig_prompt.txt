Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Download RKE2 kubeconfig to localhost
Description Task 1: Download the RKE2 kubeconfig file to the localhost. The file will be saved in the path specified by the variable `rke2_download_kubeconf_path` with the filename specified by the variable `rke2_download_kubeconf_file_name`. The `flat` parameter is set to `yes` to ensure that the file is downloaded as a single file. The task will only run if the variable `rke2_download_kubeconf` is set to `true` and the current inventory hostname is the first server in the group specified by `rke2_servers_group_name`.

Task 2: Replace loopback IP by master server IP
Description Task 2: Replace the loopback IP (127.0.0.1 or [::1]) in the RKE2 kubeconfig file with the master server IP. The path to the kubeconfig file is specified by the variable `rke2_download_kubeconf_path` with the filename specified by the variable `rke2_download_kubeconf_file_name`. The task will only run if the variable `ansible_check_mode` is not set, the variable `rke2_download_kubeconf` is set to `true`, and the current inventory hostname is the first server in the group specified by `rke2_servers_group_name`. The task uses the `replace` module to perform the replacement, with the regular expression `127\.0\.0\.1|\[::1\]` to match the loopback IPs, and the replacement value being the IP address of the master server obtained from the `rke2_api_ip` variable or the `ansible_host` variable of the first server in the `rke2_servers_group_name` group. The task is delegated to the localhost to perform the file operations, with the `become` parameter set to `false` to avoid privilege escalation.
