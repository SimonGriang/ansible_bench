Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Create the directory for RKE2 configuration.
Description Task 1: Create the directory /etc/rancher/rke2 with root ownership, root group, and mode set to 0755.

Task 2: Set server node taints.
Description Task 2: Set the variable combined_node_taints to the value of rke2_server_node_taints when the value of rke2_type is 'server'.

Task 3: Set agent node taints.
Description Task 3: Set the variable combined_node_taints to the value of rke2_agent_node_taints when the value of rke2_type is 'agent'.

Task 4: Copy RKE2 configuration file.
Description Task 4: Copy the RKE2 configuration file from the defined template to /etc/rancher/rke2/config.yaml with root ownership, root group, and mode set to 0600. Notify the handler 'Config file changed'.

Task 5: Copy kubelet configuration file.
Description Task 5: Copy the kubelet configuration file from the template kubelet-config.yaml.j2 to /etc/rancher/rke2/kubelet-config.yaml with root ownership, root group, and mode set to 0600 if rke2_kubelet_config is not empty. Notify the handler 'Config file changed'.

Task 6: Copy Containerd Registry Configuration file.
Description Task 6: Copy the Containerd Registry Configuration file from the defined variable to /etc/rancher/rke2/registries.yaml with root ownership, root group, and mode set to 0600 if rke2_custom_registry_mirrors or rke2_custom_registry_configs is not empty. Notify the handler 'Config file changed'.

Task 7: Start RKE2 service on nodes.
Description Task 7: Start the RKE2 service specified by rke2_service_name and enable it at boot. Retry starting the service up to 10 times with a delay of 3 seconds between retries. Set the environment variable RKE2_TOKEN to the value of rke2_token. Notify the handler 'Service (re)started'.

Task 8: Mask other RKE2 services on nodes.
Description Task 8: Mask and disable RKE2 services that are not the current type (either 'agent' or 'server').

Task 9: Wait for remaining nodes to be ready - no CNI.
Description Task 9: Wait for nodes to be ready without CNI by checking the node statuses and ensuring that the necessary conditions are met. Retry up to 100 times with a delay of 15 seconds between retries. Check the status of nodes in the group defined by rke2_cluster_group_name. Only execute if rke2_cni is set to 'none' and the current host is the active server or the first server in the list of servers.

Task 10: Wait for remaining nodes to be ready - with CNI.
Description Task 10: Wait for nodes to be ready with CNI by checking the number of nodes that are ready. Retry up to 100 times with a delay of 15 seconds between retries. Only execute if rke2_cni is not set to 'none' and the current host is the active server or the first server in the list of servers.
