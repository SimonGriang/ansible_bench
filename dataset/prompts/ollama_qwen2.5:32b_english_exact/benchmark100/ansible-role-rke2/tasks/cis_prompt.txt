Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Create etcd group
Description Task 1: This task creates a new group named 'etcd' on the target system.

Task 2: Create etcd user
Description Task 2: This task creates a new user named 'etcd' and assigns it to the 'etcd' group. The user has a restricted shell and a comment set to 'etcd user'.

Task 3: Copy systemctl config file for kernel hardening
Description Task 3: This task copies a file for kernel hardening to /etc/sysctl.d/60-rke2-cis.conf. The source file path is dynamically chosen based on conditions related to file writability and partition status. The file is set to mode 0600. It also notifies the 'Restart systemd-sysctl' handler to ensure that the changes take effect.

Task 4: Flush handlers
Description Task 4: This task ensures that all pending handler notifications are processed immediately, triggering any handlers that have been notified.
