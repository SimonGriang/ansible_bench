Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Download RKE2 kubeconfig to localhost
Description Task 1: This task is responsible for downloading the RKE2 kubeconfig file from the remote server to the local host. The source file is located at /etc/rancher/rke2/rke2.yaml and will be saved in the destination path specified by the variable 'rke2_download_kubeconf_path' and the file name specified by 'rke2_download_kubeconf_file_name'. The task will only execute if the boolean variable 'rke2_download_kubeconf' is true and if the host is the first member of the group specified by 'rke2_servers_group_name'.

Task 2: Replace loopback IP by master server IP
Description Task 2: This task replaces the loopback IP addresses (127.0.0.1 and [::1]) with the master server IP in the downloaded RKE2 kubeconfig file. The IP address is obtained from the variable 'rke2_api_ip' or, if not set, defaults to the IP of the first host in the group specified by 'rke2_servers_group_name'. The task is to be run on the localhost and does not require privilege escalation ('become: false'). It only executes if the playbook is not in check mode, the 'rke2_download_kubeconf' variable is true, and the host is the first member of the group specified by 'rke2_servers_group_name'.
