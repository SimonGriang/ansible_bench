Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Cordon and Drain the node {{ rke2_node_name }}  
Description Task 1: Use the kubectl command to cordon and drain a specified node within an RKE2 cluster. The task should retry until the node is drained, with a delay of 15 seconds between retries and a maximum of 100 retries. The task should be run once from an active server, and it should only execute if rke2_drain_node_during_upgrade is true.  

Task 2: Restart RKE2 service on {{ rke2_node_name }}  
Description Task 2: Restart the RKE2 service on a specified node. Notify a handler to restart the service if there are any changes.  

Task 3: Wait for all nodes to be ready again  
Description Task 3: Use kubectl to check the status of all nodes and wait until all nodes are in the "Ready" state. The task should retry until the number of ready nodes equals the total number of nodes in the cluster, with a delay of 15 seconds between retries and a maximum of 100 retries. The task should be run once from an active server.  

Task 4: Uncordon the node {{ rke2_node_name }}  
Description Task 4: Use the kubectl command to uncordon a specified node within an RKE2 cluster. The task should be run once from an active server, and it should only execute if rke2_drain_node_during_upgrade is true.  

Task 5: Wait for all pods to be ready again  
Description Task 5: Use kubectl to check the status of all pods across all namespaces and wait until all pods are in the Running or Succeeded state. The task should retry until the number of pods not in the Running or Succeeded state is zero, with a delay of 15 seconds between retries and a maximum of 100 retries. The task should be run once from an active server, and it should only execute if rke2_wait_for_all_pods_to_be_ready is true.  

Task 6: Wait for all pods to pass readiness checks  
Description Task 6: Use kubectl to wait until all pods pass their readiness checks across all namespaces. The task should retry until all pods are ready, with a delay of 15 seconds between retries and a maximum of 100 retries. The task should be run once from an active server, and it should only execute if rke2_wait_for_all_pods_to_be_healthy is true.
