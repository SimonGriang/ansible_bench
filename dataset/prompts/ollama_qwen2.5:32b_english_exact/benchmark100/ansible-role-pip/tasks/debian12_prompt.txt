Task 1: debian12 | Get python3 version installed

Task 2: debian12 | Remove EXTERNALLY-MANAGED
Description Task 2: This task removes the file `/usr/lib/python3.11/EXTERNALLY-MANAGED` if the Python 3 version installed on the system is 3.11. The task uses a conditional `when` statement to check if `py3ver` is defined and if the output of `py3ver.stdout` contains the string "3.11". If both conditions are met, the file is removed.
