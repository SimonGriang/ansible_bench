Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the assert.yml file which contains tasks that perform assertions. This task runs once and is delegated to localhost.

Task 2: Install mysql
Description Task 2: Install MySQL packages specified in the variable `mysql_packages`. This task notifies two handlers: Set root password and Systemctl daemon-reexec to be executed.

Task 3: Configure mysql server
Description Task 3: Configure MySQL server settings by writing to the configuration file located at `{{ mysql_configuration_destination }}/{{ mysql_name }}-server.cnf`. The task iterates over the list `mysql_configuration_options` to set the configuration options and notifies the Restart mysql server handler.

Task 4: Configure mysql client
Description Task 4: Configure MySQL client settings by writing to the configuration file located at `{{ mysql_configuration_destination }}/{{ mysql_name }}-client.cnf`. The task sets the `socket` option in the `client` section.

Task 5: Initialize mysql
Description Task 5: Initialize MySQL database only on Alpine or Archlinux distributions by executing the command specified in the variable `mysql_initialize_command`.

Task 6: Start and enable mysql
Description Task 6: Start the MySQL service and ensure it starts on boot.

Task 7: Flush handlers
Description Task 7: Ensure all pending handlers are executed.

Task 8: Place my.cnf
Description Task 8: Place a template file `my.cnf.j2` into the destination `/root/.my.cnf` with the permissions set to `0640`.

Task 9: Create databases
Description Task 9: Create databases as defined in the `mysql_databases` variable. The task iterates over the list and sets database parameters such as name, state, target, encoding, and collation. The task uses root user with the password specified in `mysql_root_password` and is conditional on the `mysql_databases` being defined. This task does not log.

Task 10: Create users
Description Task 10: Create MySQL users as defined in the `mysql_users` variable. The task iterates over the list and sets user parameters such as name, password, privileges, host, and host_all. The task uses root user with the password specified in `mysql_root_password` and is conditional on the `mysql_users` being defined. This task does not log.

Task 11: Flush handlers again
Description Task 11: Ensure all pending handlers are executed again.
