Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: Import the assert.yml file to run validation tasks on the localhost once.

Task 2: Install nginx  
Description Task 2: Ensure that the nginx package is installed on the target system.

Task 3: Place nginx.conf  
Description Task 3: Place the nginx configuration file by rendering the nginx.conf.j2 template to /etc/nginx/nginx.conf with proper permissions and validate the configuration before placing it. Notify to restart nginx if any changes are made.

Task 4: Ensure /etc/nginx/conf.d exists  
Description Task 4: Ensure that the directory /etc/nginx/conf.d exists with the correct permissions.

Task 5: Place default.conf  
Description Task 5: Place the default server configuration file by rendering the default.conf.j2 template to /etc/nginx/conf.d/default.conf with proper permissions. Notify to restart nginx if any changes are made.

Task 6: Start and enable nginx  
Description Task 6: Ensure that the nginx service is started and enabled to start on boot.
