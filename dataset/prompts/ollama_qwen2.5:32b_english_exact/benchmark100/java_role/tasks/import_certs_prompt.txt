Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Check if certificates exist
Description Task 1: Use the stat module to check if Java certificates exist at the specified paths defined in the variable `java_certs`. The results are registered in `check_java_certs`.

Task 2: Fail if some certificate doesn't exist
Description Task 2: If any certificate path from `java_certs` does not exist, the playbook should fail with a message indicating which certificate path does not exist.

Task 3: Setting keystore variables for java versions less than 11
Description Task 3: Set a fact for `java_keystore_dir` if Java version is less than 11. Use `java_keystore_dir_old` as the default value if `java_keystore_dir` is not defined or is `None`.

Task 4: Setting keystore variables for java versions 11 and above
Description Task 4: Set a fact for `java_keystore_dir` if Java version is 11 or greater. Use `java_keystore_dir_new` as the default value if `java_keystore_dir` is not defined or is `None`.

Task 5: Import SSL certificates
Description Task 5: For each certificate in `java_certs`, import the SSL certificate into the Java keystore located at `{{ java_open_jdk_home }}/{{ java_keystore_dir }}/cacerts`. The keystore should be created if it doesn't exist, and the certificate alias is specified in `java_cert_alias`.
