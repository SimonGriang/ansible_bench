Task 1: Remove conflicting packages
Description Task 1: This task removes packages that may conflict with the ones that will be installed later by setting the state of the packages listed in the variable `core_dependencies_conflicting_packages` to absent.

Task 2: Install packages
Description Task 2: This task installs the packages listed in the variable `core_dependencies_packages`. It also updates the package cache before installing to ensure the latest package information is used. After installation, it triggers the handler to gather facts.

Description Task 3: This task flushes all handlers to ensure that any pending handler calls are executed immediately.
