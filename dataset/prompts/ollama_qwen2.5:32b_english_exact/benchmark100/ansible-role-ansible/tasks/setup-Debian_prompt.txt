Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Enable Backports repository.
Description Task 1: This task adds the Debian backports repository for systems with Debian version less than 9. It updates the package cache after adding the repository.

Task 2: Set the default_release option for older Debian versions.
Description Task 2: This task sets the default release option to use backports for older Debian versions (less than 9). This is to ensure that backports are used as the default source for packages.

Task 3: Install Ansible.
Description Task 3: This task installs the Ansible package using the specified package state (e.g., present, latest) and the default release set previously, which might be backports for older Debian systems.
