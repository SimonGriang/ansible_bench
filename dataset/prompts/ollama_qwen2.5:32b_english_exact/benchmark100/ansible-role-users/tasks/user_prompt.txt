Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Create a local directory for SSH keys for a given user
Description Task 1: The task creates a directory for storing SSH keys for a specified user, checks if user.manage_ssh_key is defined and true, and delegates the operation to the localhost with no privilege escalation.

Task 2: Manage a user account
Description Task 2: This task manages the user account by setting various user attributes such as state, comment, create_home, password, password_lock, uid, group, groups, home, shell, update_password, expires, and system.

Task 3: Set sudo options for a user
Description Task 3: This task sets sudo options for a user by rendering a template and placing it in /etc/sudoers.d/, only if user.sudo_options is defined.

Task 4: Remove sudo options for a user
Description Task 4: This task removes sudo options for a user if user.sudo_options is not defined, by removing the file from /etc/sudoers.d/.

Task 5: Generate a private SSH key for a user
Description Task 5: The task generates a private SSH key for a user using a command, checks if user.manage_ssh_key is defined and true, and delegates the operation to the localhost with no privilege escalation.

Task 6: Generate a public SSH key for a user
Description Task 6: This task generates a public SSH key for a user using a shell command, checks if user.manage_ssh_key is defined and true, and delegates the operation to the localhost with no privilege escalation.

Task 7: Convert SSH key to PPK for a user
Description Task 7: The task converts the SSH key to PPK format for a user, checks if user.manage_ssh_key is defined and true, and delegates the operation to the localhost with no privilege escalation.

Task 8: Get or set the home directory for a user
Description Task 8: This block task gets the system user data to set the base home directory. If the user is not found, it sets the home directory to /home.

Task 9: Create .ssh directory for a user
Description Task 9: This task creates a .ssh directory in the user's home directory with specific permissions, checks if user.manage_ssh_key is defined and true or user.private_keys is defined, and runs with privilege escalation to the user.

Task 10: Deploy authorized keys for a user
Description Task 10: This task deploys authorized keys to the user's .ssh directory from the list defined in user.authorized_keys.

Task 11: Remove unauthorized keys for a user
Description Task 11: This task removes unauthorized keys from the user's .ssh directory based on the list defined in user.unauthorized_keys.

Task 12: Copy generated private SSH key for a user
Description Task 12: This task copies the generated private SSH key to the user's .ssh directory, checks if user.copy_private_key is defined and true, and runs with privilege escalation to the user.

Task 13: Check the user's password valid time
Description Task 13: This task checks the user's password valid time by running a command and registering the output, checks if user.state is defined and not "absent".

Task 14: Set the user's password valid time
Description Task 14: This task sets the user's password valid time using the chage command, checks if user.password_validity_days is defined and if the current password valid time is different from the defined one.

Task 15: Place private key file for a user
Description Task 15: This task places private key files in the user's .ssh directory, checks if user.private_keys is defined, and runs with privilege escalation to the user.
