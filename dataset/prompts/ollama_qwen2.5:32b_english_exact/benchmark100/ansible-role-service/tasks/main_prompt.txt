Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the tasks defined in assert.yml, running only once and delegating the task to localhost.

Task 2: Install required packages
Description Task 2: Ensure that the packages listed in the variable `service_required_packages` are installed on the system and notify the handler to gather facts.

Task 3: Configure systemd service
Description Task 3: For each item in the `service_list`, if the service manager is systemd, template the `systemd.j2` file and place it in `/etc/systemd/system/{{ item.name }}.service`, setting the mode to 0644. Notify the handler to reload the systemd daemon.

Task 4: Configure sysvinit service
Description Task 4: For each item in the `service_list`, if the service manager is sysvinit, upstart, or openrc, template the `sysvinit.j2` file and place it in `/etc/init.d/{{ item.name }}`, setting the mode to 0755.

Task 5: Manage service
Description Task 5: For each item in the `service_list`, manage the service according to the state and enabled parameters defined for each item, if they are defined.

Task 6: Flush handlers
Description Task 6: Ensure all pending handlers are executed immediately.
