The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: check if all variables have been set correctly

Task 2: wait for host (when configured)
Description Task 2: This task waits for a specific port (defaulted to SSH port 22) on the specified host until it becomes available, based on the `bootstrap_timeout`. The task is skipped if the connection type is container, docker, or community.docker.docker.

Task 3: prepare system
Description Task 3: This task block includes testing the connection, handling connection failures by logging a note, and gathering bootstrap facts (raw). It also installs bootstrap packages (raw) based on the `bootstrap_os_family` and `bootstrap_install.raw` command.

Task 4: ensure system is prepared by issuing ansible modules.
Description Task 4: This task block ensures system preparation by gathering ansible facts and installing bootstrap packages using the `package` module. It loops over `bootstrap__facts_packages.split()` to install each package listed.
