Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the assert.yml file to run assertions that verify the environment before proceeding with further tasks. This task should run once and be delegated to localhost.

Task 2: Install openvpn packages
Description Task 2: Install the OpenVPN packages listed in the variable `openvpn_packages` on the target system. Ensure these packages are present.

Task 3: Setup openvpn server or client
Description Task 3: Include the tasks defined in the file that corresponds to the value of the variable `openvpn_role`. This could be a file for setting up the server or client based on the role.

Task 4: Start and enable openvpn
Description Task 4: Ensure the OpenVPN service, defined in the variable `openvpn_service`, is both started and set to start on boot. This ensures the service is running and configured to start automatically on system boot.
