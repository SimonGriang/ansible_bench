Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: gather_facts | Lookup bootstrap facts
Description Task 1: The task reads the content of the /etc/os-release file without requiring elevated privileges and registers the output under the variable `bootstrap_facts`.

Task 2: gather_facts | Set bootstrap facts (I)
Description Task 2: This task sets the facts for `bootstrap_distribution` and `bootstrap_distribution_major_version` by iterating over the values of `bootstrap_os_family_map` and applying regex to the `bootstrap_facts.stdout_lines` to extract the major version number. It only executes if `bootstrap_facts.rc` equals 0, `bootstrap_distribution` is not already defined, and the `bootstrap_facts.stdout` matches thePRETTY_NAME with the value from `bootstrap_search`.

Task 3: gather_facts | Set bootstrap facts (II)
Description Task 3: This task sets the `bootstrap_os_family` fact by iterating over the dictionary `bootstrap_os_family_map` and assigns the key of the dictionary to `bootstrap_os_family` if the `bootstrap_distribution` is found within the dictionary value. It also includes a `loop_control` for better readability of the loop labels.
