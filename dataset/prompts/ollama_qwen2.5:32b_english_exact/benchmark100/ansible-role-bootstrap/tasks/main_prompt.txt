Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the assert.yml file to run assertions for the current environment. This task runs once and is delegated to localhost.

Task 2: Wait for port to be available
Description Task 2: Wait until the specified port (defaulting to 22 if ansible_port is not defined) becomes available, based on the bootstrap_timeout variable, but only when certain conditions on the ansible_connection are met and bootstrap_wait_for_host is true.

Task 3: Prepare system
Description Task 3: Execute a series of tasks to prepare the system. This includes testing the connection with a specified timeout, testing if sudo is available, and handling any failures by gathering bootstrap facts and installing necessary packages using raw commands.

Task 4: Gather ansible facts
Description Task 4: Gather information about the system using the setup module, without requiring privilege escalation.

Task 5: Install bootstrap packages (package)
Description Task 5: Install necessary bootstrap packages using the package module. The packages are specified by splitting the bootstrap_facts_packages string into individual items and installing them one by one. Privilege escalation is controlled by the bootstrap_become variable.
