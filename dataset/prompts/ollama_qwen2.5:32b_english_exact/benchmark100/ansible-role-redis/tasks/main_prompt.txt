Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the assert.yml file to perform assertions. The task should run once and be delegated to localhost.

Task 2: Enable redis module stream (RHEL 8)
Description Task 2: Enable the redis module stream for RHEL 8 systems using the dnf package manager. This task should only run if the OS family is RedHat and the distribution major version is 8.

Task 3: Install redis
Description Task 3: Install the redis packages listed in the variable redis_packages.

Task 4: Configure redis
Description Task 4: Use a template to configure redis by copying a configuration file specific to the distribution (e.g., redis.conf-CentOS.j2) to the destination directory specified by the redis_configuration_directory variable. The template should also set the owner, group, and mode specified by the redis_owner, redis_group, and redis_mode variables respectively. Notify the Restart redis handler after the configuration is applied.

Task 5: Start and enable redis
Description Task 5: Start the redis service and enable it to start on boot. The service name should be specified by the redis_service variable.
