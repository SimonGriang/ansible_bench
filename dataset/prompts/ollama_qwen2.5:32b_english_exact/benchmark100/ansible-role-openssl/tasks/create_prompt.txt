Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: create | Create ssl key
Description Task 1: Use the community.crypto.openssl_privatekey module to create an SSL key file. The key will be saved in the directory specified by the variable `openssl_key_directory`, with the file name being the name of the item followed by `.key`. The file will have a mode of `640` and will be owned by the user and group specified by `openssl_file_owner` and `openssl_file_group`.

Task 2: create | Create ssl csr
Description Task 2: Use the community.crypto.openssl_csr module to create an SSL CSR file. The CSR will be saved in the directory specified by the variable `openssl_csr_directory`, with the file name being the name of the item followed by `.csr`. The private key used for this CSR will be the one created in the previous step. The file will have a mode of `644` and will be owned by the user and group specified by `openssl_file_owner` and `openssl_file_group`.

Task 3: create | Create ssl certificates
Description Task 3: Use the community.crypto.x509_certificate module to create an SSL certificate file. The certificate will be saved in the directory specified by the variable `openssl_crt_directory`, with the file name being the name of the item followed by `.crt`. The certificate will be self-signed using the CSR created in the previous step and the private key. The file will have a mode of `644` and will be owned by the user and group specified by `openssl_file_owner` and `openssl_file_group`.

Task 4: create | Create PKCS#12 file
Description Task 4: Use the community.crypto.openssl_pkcs12 module to create a PKCS#12 file. The PKCS#12 file will be saved in the directory specified by the variable `openssl_key_directory`, with the file name being the name of the item followed by `.p12`. The PKCS#12 file will contain the private key and the certificate created in the previous steps. It will have a mode of `640` and will be owned by the user and group specified by `openssl_file_owner` and `openssl_file_group`.

Task 5: create | Read private key
Description Task 5: Use the ansible.builtin.slurp module to read the contents of the SSL key file and register the result in a variable named `openssl_private_key`.

Task 6: create | Read certificate
Description Task 6: Use the ansible.builtin.slurp module to read the contents of the SSL certificate file and register the result in a variable named `openssl_certifcate`.

Task 7: create | Create combined private_key and certificate file
Description Task 7: Use the ansible.builtin.copy module to create a combined file that contains both the private key and the certificate. The combined file will be saved in the directory specified by the variable `openssl_key_directory`, with the file name being the name of the item followed by `.keycrt`. The file will have a mode of `640` and will be owned by the user and group specified by `openssl_file_owner` and `openssl_file_group`. The content of the file will be the decoded and trimmed contents of the SSL key and certificate files.
