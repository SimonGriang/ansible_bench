Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the assert.yml file to perform assertions and run once on the localhost.

Task 2: Install required packages
Description Task 2: Install the packages listed in the variable 'selinux_requirements' and notify the 'Gather facts' handler.

Task 3: Flush handlers
Description Task 3: Execute any pending handlers immediately.

Task 4: Configure selinux
Description Task 4: Configure SELinux if the status is defined and the connection type is not container, docker, or community.docker.docker. This task includes a block with two tasks inside.

Task 5: Manage selinux
Description Task 5: Manage SELinux settings with the state and policy defined in the variables 'selinux_state' and 'selinux_policy', and notify the 'Reboot' handler.

Task 6: Manage selinux booleans
Description Task 6: Manage SELinux booleans for each item in the 'selinux_booleans' list, setting the state and persistence according to the item's attributes, and only if 'selinux_booleans' is defined.
