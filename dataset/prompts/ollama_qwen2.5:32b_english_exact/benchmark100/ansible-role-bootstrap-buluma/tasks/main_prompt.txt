Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the tasks from assert.yml file to be executed in the current playbook context. This task runs once and delegates to localhost.

Task 2: Wait for port to be available
Description Task 2: Wait for a given port, defaulting to SSH (22), to become available on the target host. This task is skipped if the host is connected via container, docker, or if the bootstrap_wait_for_host variable is not set.

Task 3: Prepare system
Description Task 3: Prepare the system by testing the connection and sudo capability without requiring elevated permissions. If the system setup fails, it includes gathering bootstrap facts and installing bootstrap packages using raw commands, with specific conditions based on the operating system family.

Task 4: Gather ansible facts
Description Task 4: Gather facts about the system using the setup module without requiring elevated permissions.

Task 5: Install bootstrap packages (package)
Description Task 5: Install a set of packages defined in the bootstrap_facts_packages variable using the package module, with elevated permissions based on the value of the bootstrap_become variable.
