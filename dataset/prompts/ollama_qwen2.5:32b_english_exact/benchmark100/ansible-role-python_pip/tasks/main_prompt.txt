Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: This task imports another tasks file named assert.yml. It runs once and delegates execution to localhost.

Task 2: Install python pip
Description Task 2: This task installs Python pip packages defined in the variable python_pip_packages. The state is set to present.

Task 3: Configure pip proxy
Description Task 3: This task configures the pip proxy by setting an index-url option in /etc/pip.conf under the global section if the variable python_pip_proxy is defined.

Task 4: Trust hosts
Description Task 4: This task adds trusted hosts for pip by setting the trusted-host option in /etc/pip.conf under the global section if the variable python_pip_trusted_host is defined.

Task 5: Update pip.
Description Task 5: This task updates pip to the latest version, using the pip module. The update is conditional on the variable python_pip_update being true and the OS not being in the list [ "bookworm", "noble" ] or being Alpine.

Task 6: Install requested modules
Description Task 6: This task installs requested Python modules using pip. It iterates over the list defined in python_pip_modules, installing each module with its specified state and version if provided. The installation is conditional on the OS not being in the list [ "bookworm", "noble" ] or being Alpine.
