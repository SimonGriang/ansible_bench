Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml  
Description Task 1: This task imports another task file named assert.yml. It runs only once and is delegated to localhost to ensure that the assertions defined in assert.yml are executed.

Task 2: Manage automatic service management  
Description Task 2: This task manages the automatic service management on systems where the package manager is apt. It contains two sub-tasks that handle enabling and disabling the automatic service management based on the variable apt_autostart_state.

Task 3: Disable automatic service management on installation  
Description Task 3: If apt_autostart_state is set to "disabled", this task creates a file at /usr/sbin/policy-rc.d with content "exit 101" and mode 755 to disable automatic service management during installation.

Task 4: Enable automatic service management on installation  
Description Task 4: If apt_autostart_state is set to "enabled", this task removes the file at /usr/sbin/policy-rc.d to enable automatic service management during installation.
