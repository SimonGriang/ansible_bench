Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Load OS-specific vars.
Description Task 1: Load variables specific to the operating system by including the first found file among distribution-specific, OS family-specific, or the generic main.yml under the vars directory.

Task 2: Include tasks for RedHat setup.
Description Task 2: Include tasks for setting up the system if it is a RedHat family system.

Task 3: Include tasks for Debian setup.
Description Task 3: Include tasks for setting up the system if it is a Debian family system.

Task 4: Install Docker packages.
Description Task 4: Install Docker packages based on the variable `docker_packages`, with the state defined by `docker_packages_state`. Notify the restart of Docker if necessary. Ignore errors if in check mode and only apply if the Ansible version is less than 2.12 or the OS family is not RedHat or Debian.

Task 5: Install Docker packages (with downgrade option).
Description Task 5: Install Docker packages with the ability to downgrade if needed based on the variable `docker_packages`, with the state defined by `docker_packages_state`. Notify the restart of Docker if necessary. Ignore errors if in check mode and only apply if the Ansible version is 2.12 or greater and the OS family is RedHat or Debian.

Task 6: Install docker-compose plugin.
Description Task 6: Install the Docker Compose plugin based on the variable `docker_compose_package`, with the state defined by `docker_compose_package_state`. Notify the restart of Docker if necessary. Ignore errors if in check mode and only apply if the `docker_install_compose_plugin` variable is true and the Ansible version is less than 2.12 or the OS family is not RedHat or Debian.

Task 7: Install docker-compose-plugin (with downgrade option).
Description Task 7: Install the Docker Compose plugin with the ability to downgrade if needed based on the variable `docker_compose_package`, with the state defined by `docker_compose_package_state`. Notify the restart of Docker if necessary. Ignore errors if in check mode and only apply if the `docker_install_compose_plugin` variable is true and the Ansible version is 2.12 or greater and the OS family is RedHat or Debian.

Task 8: Ensure /etc/docker/ directory exists.
Description Task 8: Ensure that the `/etc/docker/` directory exists with the permission mode set to 0755 if there are any Docker daemon options to configure.

Task 9: Configure Docker daemon options.
Description Task 9: Configure the Docker daemon options by creating a `daemon.json` file under `/etc/docker/` with the content of `docker_daemon_options` in JSON format and permission mode set to 0644 if there are any Docker daemon options to configure. Notify the restart of Docker if necessary.

Task 10: Ensure Docker is started and enabled at boot.
Description Task 10: Ensure that the Docker service is started and enabled at boot based on the variables `docker_service_state` and `docker_service_enabled`. Ignore errors if in check mode and only apply if the `docker_service_manage` variable is true.

Task 11: Ensure handlers are notified now to avoid firewall conflicts.
Description Task 11: Flush all handlers to avoid any potential conflicts with firewall rules.

Task 12: Include tasks for Docker Compose setup.
Description Task 12: Include tasks for setting up Docker Compose if the `docker_install_compose` variable is true.

Task 13: Get docker group info using getent.
Description Task 13: Use the `getent` module to get the info on the docker group if there are any users to add to the docker group.

Task 14: Check if there are any users to add to the docker group.
Description Task 14: Check if any of the users listed in `docker_users` are not already members of the docker group. Set the fact `at_least_one_user_to_modify` to true if so.

Task 15: Include tasks for managing Docker users.
Description Task 15: Include tasks for managing Docker users if the fact `at_least_one_user_to_modify` is defined.
