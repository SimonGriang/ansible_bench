Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Ensure old versions of Docker are not installed.
Description Task 1: Remove any old Docker packages listed in the variable `docker_obsolete_packages`.

Task 2: Add Docker GPG key.
Description Task 2: Add the GPG key specified in the variable `docker_yum_gpg_key` if the variable `docker_add_repo` is true.

Task 3: Add Docker repository.
Description Task 3: Download and install the Docker repository file from the URL specified in `docker_yum_repo_url` to `/etc/yum.repos.d/docker-{{ docker_edition }}.repo` with ownership set to root:root and permissions set to 0644 if `docker_add_repo` is true.

Task 4: Configure Docker Nightly repo.
Description Task 4: Enable or disable the Docker nightly repository in the file `/etc/yum.repos.d/docker-{{ docker_edition }}.repo` based on the value of `docker_yum_repo_enable_nightly` if `docker_add_repo` is true.

Task 5: Configure Docker Test repo.
Description Task 5: Enable or disable the Docker test repository in the file `/etc/yum.repos.d/docker-{{ docker_edition }}.repo` based on the value of `docker_yum_repo_enable_test` if `docker_add_repo` is true.

Task 6: Configure containerd on RHEL 8.
Description Task 6: When the major version of the distribution is 8, ensure runc is not installed, ensure container-selinux is installed, and ensure containerd.io is installed.
