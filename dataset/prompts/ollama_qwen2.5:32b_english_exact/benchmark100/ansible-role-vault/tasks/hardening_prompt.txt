Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: hardening | Disable swap
Description Task 1: This task disables swap on the system both temporarily and permanently, conditional on the variable vault_hardening_disable_swap. The task will be skipped if there is no swap space available.

Task 2: hardening | Disable swap now
Description Task 2: This task disables swap space immediately using the swapoff command. It is part of the block defined by the first task and will execute only if there is swap space available (ansible_swaptotal_mb > 0).

Task 3: hardening | Disable swap permanently
Description Task 3: This task ensures that swap is not re-enabled after a reboot by removing the swap mount entry. It is part of the block defined by the first task.

Task 4: hardening | Disable core dumps
Description Task 4: This task configures the system to disable core dumps for all users by setting the core limit type and item to 0 both for hard and soft limits. This task is conditional on the variable vault_hardening_disable_core_dumps.

Task 5: hardening | Disable Shell Command History
Description Task 5: This task creates a shell script to disable the recording of certain commands in the shell history by setting the HISTIGNORE environment variable. This task is conditional on the variable vault_hardening_disable_shell_command_history.

Task 6: hardening | Configure SELinux / AppArmor
Description Task 6: This task configures the security policies for SELinux and AppArmor. The block contains tasks for enabling and configuring SELinux and enabling AppArmor in enforcing mode, conditional on the variable vault_hardening_configure_selinux_apparmor.

Task 7: hardening | Enable SELinux
Description Task 7: This task enables SELinux, including installing the selinux-policy package and setting the SELinux policy to targeted and enforcing mode. This task is part of the block defined by the previous task and is conditional on the SELinux status being enabled.

Task 8: hardening | Install selinux-policy
Description Task 8: This task installs the selinux-policy package, ensuring that the SELinux policy is available for setting SELinux policies.

Task 9: hardening | Set SELinux policy
Description Task 9: This task sets the SELinux policy to targeted and enforcing mode after the selinux-policy package has been installed.

Task 10: hardening | Enable AppArmor (enforcing)
Description Task 10: This task enables AppArmor in enforcing mode on the system, conditional on the AppArmor status being enabled.
