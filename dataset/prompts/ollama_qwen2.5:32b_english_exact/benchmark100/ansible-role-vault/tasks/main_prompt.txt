Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the assert.yml file to run assertions on the target system, this task should be executed once and delegated to localhost.

Task 2: Install prerequisites
Description Task 2: Install the required packages for Vault as defined by the variable vault_prerequisites.

Task 3: Include installation method specific tasks
Description Task 3: Dynamically include tasks from a file based on the vault_installation_method variable, which contains the installation method specific tasks.

Task 4: Add Vault environment variables
Description Task 4: Add environment variables specified in the vault_environment_settings list to the /etc/vault.d/vault.env file, and set the file mode to 0644. Notify the Restart vault handler if changes are made.

Task 5: Include hardening tasks
Description Task 5: Include tasks from the hardening.yml file to apply security hardening configurations.

Task 6: Start and enable vault
Description Task 6: Start and enable the Vault service if the vault_type variable equals "oss".

Task 7: Enable vault
Description Task 7: Enable the Vault service if the vault_type variable does not equal "oss".
