Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the assert.yml tasks file, run once and delegate to localhost.

Task 2: Install fail2ban
Description Task 2: Ensure the fail2ban package is installed with the package names defined in the variable fail2ban_packages.

Task 3: Copy filters in filter.d
Description Task 3: Copy files from the directory defined in fail2ban_filterd_path to /etc/fail2ban/filter.d/, set ownership to root:root and mode to 0640. Only execute if fail2ban_filterd_path is defined, and notify to restart fail2ban service after completion.

Task 4: Configure fail2ban.local
Description Task 4: Configure fail2ban.local by updating the specified sections and options with their respective values from the combined list of fail2ban_base_configuration and fail2ban_configuration. The mode of the file should be set to 0640 and notify to restart the fail2ban service after configuration.

Task 5: Configure jail.local
Description Task 5: Configure jail.local by updating the specified sections and options with their respective values from the combined list of fail2ban_base_jail_configuration and fail2ban_jail_configuration. The mode of the file should be set to 0640 and notify to restart the fail2ban service after configuration.

Task 6: Stat auth log file
Description Task 6: Gather information about the auth log file located at /var/log/auth.log and register the result in the variable fail2ban_auth.

Task 7: Touch auth log file
Description Task 7: Touch the auth log file at /var/log/auth.log to update its modification time or create it if it does not exist. Only execute if the auth log file does not exist.

Task 8: Start and enable fail2ban
Description Task 8: Ensure the fail2ban service is started and enabled using the name defined in the variable fail2ban_service.
