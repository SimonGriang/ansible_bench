The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: This task imports another tasks file named assert.yml. It runs once and is delegated to localhost.

Task 2: Install vsftpd
Description Task 2: This task installs the vsftpd package using the package module.

Task 3: Configure vsftpd
Description Task 3: This task uses a template to configure vsftpd by placing the rendered vsftpd.conf.j2 file to the path specified by the variable vsftpd_configuration_file. It sets the owner to root, group to root, and applies the mode specified by the variable vsftpd_configuration_file_mode. This task also notifies a handler to restart vsftpd.

Task 4: Start and enable vsftpd
Description Task 4: This task ensures that the vsftpd service is both started and enabled to start on boot.
