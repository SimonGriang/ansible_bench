Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Assert usage of systemd as an init system  
Description Task 1: This task checks whether the system uses systemd as its init system. It will fail the playbook if systemd is not detected, with a message that the playbook only works with systemd.

Task 2: Get latest release  
Description Task 2: Fetches the latest release information from the Grafana Loki repository on GitHub. It retrieves the content in JSON format and repeats the request up to 5 times if the response status is not 200. The task uses credentials from environment variables if provided.

Task 3: Set promtail version  
Description Task 3: Sets the version of promtail to the latest version fetched from the GitHub repository, excluding the leading 'v'. This task is only executed when the variable 'promtail_version' is set to "latest".

Task 4: Test if zip local archive exists  
Description Task 4: Checks if a local archive of promtail exists at a specified path. This task only runs once and on the localhost.

Task 5: Assert local binary exists  
Description Task 5: Asserts that the local promtail binary exists at the specified path. The task will fail if the binary does not exist and is dependent on the 'promtail_binary_local_dir' not being empty.

Task 6: Get checksum list  
Description Task 6: Fetches the SHA256 checksum list from the Grafana Loki releases page for a given promtail version. This task runs only once.

Task 7: Get checksum for architecture  
Description Task 7: Extracts the checksum for the specified architecture from the checksum list fetched earlier. It iterates over the list of checksums and selects the one that matches the specified architecture. This task only runs if 'promtail_binary_local_dir' is empty.
