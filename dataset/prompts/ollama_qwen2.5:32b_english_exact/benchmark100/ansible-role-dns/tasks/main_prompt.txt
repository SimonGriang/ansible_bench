Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: This task imports the tasks from assert.yml to perform initial assertions or validations, running once and delegated to localhost.

Task 2: Install dns
Description Task 2: This task installs the DNS software packages specified by the variable `dns_packages`.

Task 3: Create directories
Description Task 3: This task creates directories for DNS data and configuration. It sets specific permissions, ownership, and group for each directory.

Task 4: Create group
Description Task 4: This task ensures the group specified by `dns_group` exists.

Task 5: Create user
Description Task 5: This task creates a user for DNS operations with the specified ownership and system user properties.

Task 6: Generate rndc key
Description Task 6: This task generates a rndc key file in the DNS configuration directory using the `rndc-confgen` command.

Task 7: Set permissions on rndc key file
Description Task 7: This task sets the ownership, group, and mode for the rndc key file.

Task 8: Get the hints/root file
Description Task 8: This task fetches the named.root file from a URL and places it in the DNS data directory, with specific permissions and ownership, and only if `dns_caching_dns` is true, also notifying the Rndc reload handler.

Task 9: Create zone file
Description Task 9: This task creates DNS zone files from a template, with specific permissions, ownership, and group, and only if the type is undefined or 'primary', also notifying the Rndc reload handler.

Task 10: Add zones to configuration
Description Task 10: This task creates or updates the DNS configuration file from a template, with validation and specific ownership and group, and notifies the Restart dns handler.

Task 11: Place systemd override
Description Task 11: This task places a systemd override configuration file under certain conditions if the service manager is systemd, and reloads the systemd daemon.

Task 12: Start and enable dns
Description Task 12: This task ensures the DNS service is started and enabled at boot.
