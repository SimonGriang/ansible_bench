Below you will receive task descriptions from which you should generate an Ansible Playbook.  
The generated playbook must be valid inside an Ansible Role under the tasks/ directory (e.g., tasks/main.yml).  
Do not include hosts:, vars:, or any playbook-level headers. Only output valid task entries or blocks as expected in a role.  

Task 1: Import assert.yml
Description Task 1: Import the assert.yml file to run tasks only once and delegate it to localhost.

Task 2: Install cron
Description Task 2: Install the cron package using the package module with the package name defined by the cron_packages variable.

Task 3: Configure shell
Description Task 3: Use the lineinfile module to ensure that the line "SHELL={{ cron_shell }}" is present in the file defined by cron_configuration, replacing any existing line that starts with "SHELL". Set file permissions to 0600 and notify the Restart cron handler.

Task 4: Configure path
Description Task 4: Use the lineinfile module to ensure that the line "PATH={{ cron_path }}" is present in the file defined by cron_configuration, replacing any existing line that starts with "PATH". Set file permissions to 0600 and notify the Restart cron handler.

Task 5: Configure mailto
Description Task 5: Use the lineinfile module to ensure that the line "MAILTO={{ cron_mailto }}" is present in the file defined by cron_configuration, replacing any existing line that starts with "MAILTO". Set file permissions to 0600 and notify the Restart cron handler.

Task 6: Start and enable cron
Description Task 6: Start and enable the cron service using the service module if the cron_service variable is defined and not empty.

Task 7: Schedule requested cron jobs
Description Task 7: Schedule cron jobs defined in the cron_jobs list using the cron module. Each cron job is defined by a dictionary in the list with keys for name, minute, hour, day, month, weekday, special_time, job, state, and user. Use loop to iterate over the cron_jobs list and loop_control to label the tasks with the name of the cron job. The task should only run if the cron_jobs variable is defined.
